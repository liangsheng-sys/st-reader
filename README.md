# ST Reader · SillyTavern 聊天记录阅读器

一个 SillyTavern 第三方 UI 扩展：像小说阅读器一样读聊天记录。思维链折叠、楼内切换 swipe、划线批注、收藏楼层/收藏 swipe、选段生成脱敏分享卡片，并沿用你在 SillyTavern 里已有的主题、美化 CSS、字体与正则。

**只读。** 本扩展永远不会写、改、删、重命名任何聊天文件。

- AI 开工：先读 `docs/00_README_FOR_AI.md`。
- 人类：只读 `docs/01_REQUIREMENTS.md`、`docs/05_DECISIONS.md` 与 `docs/07_FEEDBACK.md`；开工提示词在 `docs/prompts/`。
- 安装到自己的 SillyTavern：见 `docs/SETUP_WINDOWS.md`。

T40 后仓库根就是扩展：`manifest.json`、`index.js`、`style.css`、`src/`、`vendor/` 与 `docs/`、`dev/`、`install/` 同级，无需构建。旧联接请按 [Windows 手册 §3.1](docs/SETUP_WINDOWS.md#31-t40-已有安装重做联接) 先卸载联接，再重新建立到 `E:\st-reader` 的联接。
