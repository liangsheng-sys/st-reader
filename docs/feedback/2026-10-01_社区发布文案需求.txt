# 使用教程
1. 安装后，请配置分析API和摘要API，分析API推荐高质量模型；摘要API建议快速模型
2. 插件支持旧聊天记录重建，如果是超高楼层带摘要新开聊天窗口，可以在【记忆管理】-【前情】处粘贴大总结，插件会自行处理
3. 使用【千人】进行档案记录时，需要在人物识别后，手动选择“设为重要”。
4. 插件的所有记忆数据存在后端，因此不可避免在调用时会有一点延迟，请大家每一次打开聊天记录时，给插件一点点准备的时间，或者打开面板唤醒一次插件
5. 其他具体教程，可在【设置】-【教程与配置文档】处点击查看
6. 目前测试下来召回注入token在4000-5000之间，不算少，也不算太多，在保证不失忆的情况下目前是能压到的极限，待插件彻底稳定后，会再做优化

# 功能说明
## ❤ 千人
1. 将剧情中你关注的char设为重要并进行档案整理，插件会随之更新TA的基础信息，后续剧情中的更新也会自动同步至档案处
2. 允许手动编辑
3. 图标处点击可以更换头像
4. 目前不支持反注入剧情
5. 允许多人、删除、合并同一个人

## ❤ 千结
1. 记忆系统基架，每一楼进行摘要
2. 默认最新一楼不计入摘要
3. 召回结构采用的是LLM+BM25，LLM模型=摘要模型
4. 全部字段开放编辑，允许用户手动订正

## ❤ 双丝网
1. 插件核心，通过字段进行人物当前状态，以及人物关系的维护并呈现
2. 支持用户手动修改，并在后续推演中持续校准
3. 设为关注的char会在此处显示相关情境变化和自身成长线变化，同时做了认知隔离
4. 召回会抽取相关人物发展线一同注入主楼

用于酒馆中可视化进行新旧预设的对比、缝合。
可以同时载入旧版与新版预设，快速查看条目差异，并将条目或修改后的内容迁移到另一版本，或直接拖拽到另一版本。

# **预设编辑**功能

###  🔍 对比两版预设差异

• 每条预设条目自动对比标记：相同 / 已修改 / 新增 / 已删除。
• 自动识别正文内容差异，高亮有差异的部分
• 支持忽略空白对比，空格换行的差异不再干扰视线
• 自动识别相似条目，点击查看差异。也可以开启【自由选择】功能手动选择两个预设条目进行对比查看正文差异。

###  🚚 预设缝合

• 拖拽即可迁移：同版本调顺序、跨版本搬条目。可以开启【多选】功能，选择多个条目一起拖拽至另一版本或调整位置。
• 适配柏宝箱预设分组功能，可以直接拖进已有分组，导入酒馆后预设条目和分组也不会乱。
• 支持复制/删除预设中的某项条目
• 支持撤回，改错了随时反悔
• 支持导入预设文件，支持读取酒馆内预设，改完支持保存回酒馆，也可导出为预设文件。

### 🏠 正则缝合
• 导入新旧预设后点击【正则】按钮可以拖拽正则条目至另一版本或点击迁移按钮，支持多选多个正则一键迁移或拖拽至指定位置。

### 🏠 变量预设缝合优化

• 点击【变量】按钮后可识别预设中未写入获取变量条目中的变量，支持一键写入
• 点击切换引用变量后，可以查看到未被引用的变量

### ✨ 世界书条目一键转换至预设
- 可以直接选择酒馆世界书，也可以导入世界书文件，将选中的条目加入预设。
- 支持搜索、预览正文和批量选择。
- 支持【注入预设最前】【注入预设末尾】【注入指定位置】。选择【注入指定位置】插入后自动加入对应预设分组。

### 🗂️ 项目保存

• 正文搜索 + 标签筛选，快速定位条目，高亮搜索所用的关键字
• 当前缝合进度可保存为本地项目，中途有事可以下次再慢慢处理
