## §0 设计原则

1. **字是主角。** 打开阅读器后，屏幕上 90% 是正文。工具条、设置条、抽屉平时都收起或半透明，鼠标靠近 / 手指点一下才出现。
2. **永远只读，也要看起来只读。** 界面上不出现"编辑、删除、重新生成、发送"这类字眼和图标，避免误会。切 swipe 旁边不写"设为当前"。**[NF1]**
3. **继承用户的样子。** 颜色、字体、美化 CSS 都来自用户当前 ST 主题与 Ny-font-manager；阅读器自己的外框（抽屉、工具条）只用主题变量上色，不自带配色。**[F4][F5]**
4. **少按钮。** 能用一个图标就不用两个；能放进"⋯"就不摆出来。所有图标只用 ST 已加载的 Font Awesome（下文写作 `fa-xxx`），不引入任何图片素材。
5. **退出即恢复。** 关闭阅读器，ST 主界面回到打开前的样子：同一个角色、同一个聊天、同一个 swipe、同一个滚动位置。**[NF5][F1b]**

### 1.2 聊天抽屉（左）**[F1][F8][F9][F12][F13]**

顶部四个图标页签，下面一个过滤框，再下面是列表。


| 页签 | 列表内容 | 点一下 |
|---|---|---|
| 最近 | 最近打开过的聊天（单聊 + 群聊混排），按时间倒序；群聊名后缀小字"群" | 在正文区打开 |
| 按角色 | 两级：先是角色列表（缩略头像 + 名字；ST 里收藏过的角色名后有小金星），点角色展开其全部聊天文件。顶部一行"角色 / 群组"+ 排序下拉，下面一行 ST 标签（T43，见下） | 打开该聊天 |
| 收藏 | **收藏的整个聊天**（T43、D19），最近收藏的在前，每行写"角色名 · 聊天名 · 收藏于 …"。楼 / 候选的收藏不在这里，只在右侧批注面板（"本聊天 / 全部聊天"切换） | 打开那个聊天 |
| 当前 | 只有一项：ST 此刻打开的聊天；若 ST 没开聊天则写"ST 里没有打开的聊天" | 打开 |

- 正在读的聊天在列表里有左侧 3px 主题强调色竖条。
- 列表很长时虚拟滚动（372 个角色、1730 个文件量级）。**[NF2]** T43 起"按角色"页只画视口上下几十行（行高固定：角色 46px、聊天 62px），400 个角色时 DOM 里约 25 行。
- **重新读取（T71 / D34）**：顶栏进度百分比右边一个 `fa-rotate-right` 小图标，打开了聊天才出现。点了图标转圈，从 ST 重新读一遍这个聊天，读好才换正文并回到原来那一楼；失败旧正文不动、给一句提示。和“有新内容”横幅的“点击重新加载”走同一条路。
- **收藏整个聊天（D19）**：任何聊天行鼠标移上去右上角出现 ☆，点一下收藏（变金色常亮），再点取消；阅读器顶栏右侧也有 ☆ 收藏正在读的聊天。两处同步。
- **按角色页（T43、D20）**：
  - 排序下拉第一项"跟随 ST（A-Z）"——括号里是 ST 角色列表此刻用的排序，读 `power_user.sort_field / sort_order`，比较方式和 ST 一样（收藏排序收藏的在前、名字用浏览器默认语言比较），所以顺序和 ST 里看到的一致。下拉里其余项（A-Z、Z-A、最新创建、最早创建、收藏的在前、最近聊过、聊天最多 / 最少、内容最多 / 最少）只在这次打开阅读器期间有效，不写回 ST。ST 选"随机"时退回 A-Z。
  - 标签：只列至少有一个角色用着的 ST 标签（左侧一道标签色），点选多个 = 都要有（与 ST 相同），选中的排到最前，有"清除"；标签多时只露两行，"全部标签（N）▾"展开。群组页不显示标签。
  - 过滤框在这一页叫"搜索 404 个角色…"，按名字即时过滤（展开着的角色也按聊天标题过滤）。
- 抽屉底部一行小字：`只读 · 不会修改你的聊天`（给人安心，也提醒实现者）。

### 1.3 正文 **[F1][F3][F4][F5][F6]**

- 楼层 DOM 复用 ST 类名（D10/D12），所以用户的主题、美化 CSS、正则产物、Ny-font-manager 字体全部原样命中。
- 代码块：与 ST 主界面一样的语法高亮；右上角悬浮出现 `fa-copy` 复制按钮，点后变 `fa-check` 1.5 秒。**[F3]**
- 系统楼（`isNarrator`，或 `is_system` 且名字为空 / "System" / "SillyTavern System" 且只有一个候选）以更小更淡的居中字显示，不带工具条。**被 ST 隐藏过的普通楼**（楼层菜单隐藏、`/hide`、总结插件：`is_system` 置 true 但名字与候选都不变）不算系统楼，照常显示头像、工具条、候选切换、收藏与划线，只在名字旁多一个淡色小标签"已隐藏"（悬停："在 ST 里被隐藏、不发给模型，阅读器照常显示"）。判定见 `src/ui/logic.js` 的 `isSystemLike`（I050 / T62）。
- 酒馆助手 iframe 界面楼层：显示原文/代码块，并在楼内顶部一行小字提示"此楼是交互界面，阅读器显示原文"。**[D11]**
- **原样显示（T72 / I051）**：某一楼的某个候选格式化失败（正则、Markdown、HTML 接线任何一步抛错）时，这个候选不再只剩一句"显示失败"，而是显示**没经过任何处理的原文**（转义成纯文字、保留换行，HTML 不执行），名字旁一个淡色小标签"原样显示"（悬停说明）。候选切换照常可用，换到正常的候选就恢复正常排版。点 ⋯ 展开工具，只有一个 🐞"复制错误信息"：复制阅读器版本、楼号、候选号、时间、浏览器、错误名与堆栈（**不含聊天正文**），同时把错误打到浏览器控制台，方便用户贴给作者。脱敏显示开着时原文照样遮词；遮词本身失败就不显示原文。原样显示的候选不画划线、不进分享卡片选段。
- 隐藏用户楼开启时：用户楼折成一条细线 `— 你 · 3 条 —`，点它临时展开。**[F1]**
- 隐藏 ST 已隐藏的楼开启时（T62 验收后，人类定）：`isStHidden`（`is_system` 且不是系统楼）的用户楼和角色楼折成 `— 已隐藏 · 3 条 —`。两个开关有交集不重合，都开时相邻的合成一段；全是用户楼仍写"你"，全是隐藏楼写"已隐藏"，混在一起写 `— 收起 N 条 —`。判定在 `logic.js` 的 `isFolded` / `foldRuns`。

**两种阅读模式** **[F1]**

| | 分页模式（像电子书） | 滚动模式（像网页） |
|---|---|---|
| 翻页 | 点正文左 1/3 = 上一页，右 1/3 = 下一页，中间 1/3 = 呼出/收起顶栏与设置钮；键盘 `←` `→` `PageUp` `PageDown` `空格` | 鼠标滚轮 / 拖动，到底自动续接下一批楼层 |
| 一页是什么 | 一屏。长楼（2 万字）会跨多屏；楼层之间不强制换页 | 无页的概念 |
| 进度显示 | 底部正中一行极淡小字：`第 128–131 楼 · 共 312 楼 · 41%`；另有贴底 2px 进度线 | 同上，随滚动更新 |
| 跳楼 | 点进度小字 → 弹出小输入框"跳到第 __ 楼" | 同 |

> core 按每批 30 楼加载（03 §4.5），这对用户不可见：用户只感到"一页一页"或"一直往下"。

楼层工具条：鼠标进入楼层 150 ms 后在该楼**右上角外侧**淡入（桌面宽屏落在正文栏右边留白里，不压文字）；移开 600 ms 后淡出。手机上点名字行右端的 `⋯` 才出现，贴在名字行下方。

| 图标 | 名称（悬停提示） | 行为 | F |
|---|---|---|---|
| `fa-bookmark` | 收藏这一楼 | 切换；已收藏时实心并在名字左侧显示一个小书签角标 | F8 |
| `fa-star` | 收藏这个 swipe | **只在该楼有 ≥2 个 swipe 时出现**；收藏的是"当前显示的第几个 swipe"；已收藏时实心，且 swipe 计数旁显示小星 | F8 |
| `fa-brain` | 展开 / 收起思维链 | 与点"思考了 N 秒"一样；该 swipe 无思维链时此图标不出现 | F1a |
| `fa-copy` | 复制本楼文字 | 复制当前显示的 swipe 的纯文本（正则后、去 HTML），提示"已复制" | — |
| `fa-image` | 用这一楼生成卡片 | 以本楼（当前 swipe）为选段打开卡片工作台 | F2 |

> 绝不出现：编辑、删除、重新生成、分支、隐藏楼层等 ST 原生按钮；也不使用 `.mes_button` `.mes_edit` `.swipe_right` 等 ST 按钮类名（D10）。

### 1.5 选中文字浮层 **[F7][F2][F2a][F9]**

用鼠标（或手指）在正文里选中文字，松开后在选区**上方**出现一条小浮层：

```
          ╭───────────────────────────────────────────────╮
          │  ●  ●  ●  ●   │  ✎ 批注  │  🖼 卡片  │  ⊘ 屏蔽  │
          ╰───────────────────────────────────────────────╯
                 ▲ 选区：她把伞收了起来
```

| 元素 | 行为 | F |
|---|---|---|
| 四个色点（黄 / 绿 / 蓝 / 粉） | 点一下即划线，浮层消失。色值为半透明底色，在浅色与深色主题上都清楚，且不改变字色 | F7 |
| `fa-pen` 批注 | 先按默认黄色划线，再在选区下方展开一个小输入框（多行，自动增高），`Ctrl+Enter` 或点外面即保存 | F7 |
| `fa-image` 卡片 | 以选区打开卡片工作台；**可跨楼层选** | F2 |
| `fa-eye-slash` 屏蔽 | 点主体：把选中的词加入**持久屏蔽词表**（只影响卡片，不影响阅读器正文，也不影响聊天）；提示"已加入屏蔽词：xxx，只作用于分享卡片"。右侧小 `▾`：选"设为替换词…"，弹出小框把这个词加进**替换规则表**（换成文字或小图案，见 §6.4）。选区超过 30 字或跨楼时此按钮变灰，悬停提示"请选一个词" | F2a |

**特殊情况**
- **跨楼选区**：只有"卡片"可用；色点与批注变灰，悬停提示"划线请在同一楼内"。
- **点已有划线**：出现同位置浮层，变为"换色（四色点）/ ✎ 编辑批注 / 🗑 取消划线"。取消划线是删阅读器自己的批注数据，不是删聊天，文案写"取消划线"而不是"删除"。
- **有批注的划线**：划线末尾显示一个极小的 `fa-comment` 角标；鼠标悬停显示批注全文气泡。
- **手机**：为避开系统自带的复制菜单，浮层固定在屏幕底部（贴在安全区之上），而不是选区上方。

## §5 swipe 切换与每个 swipe 的思维链 **[F1b][F1a][F8]**

### 5.1 位置与样子

在**名字行的最右端**（桌面在楼层工具条出现位置的下方，互不遮挡；手机在 `⋯` 左侧）：

```
爱丽丝   9月27日 21:04                                 ◂  2 / 5  ▸
                                                          ‾‾‾
                                                          ↑ 一个小圆点在数字下方 = "ST 里现在选的是这个"
```

| 细节 | 规则 |
|---|---|
| 何时出现 | 该楼 ≥ 2 个 swipe 才出现；单 swipe 楼不显示任何切换控件 |
| 外观 | 两个细箭头 `fa-chevron-left` / `fa-chevron-right` + 等宽数字 `2 / 5`，字号比名字小一号，颜色 = 正文色 60% 透明度；鼠标悬停提亮 |
| 到头 | 第 1 个时 ◂ 变淡不可点；最后一个时 ▸ 变淡不可点（**不循环**，也**不触发生成**，这是与 ST 原生最关键的区别） |
| 点数字 | 弹出一个小列表：`1 · 21:02 · "雨还在下……"`、`2 · 21:04 · "雨停了……" ●`，每行是该 swipe 的时间与开头一句，点即跳转。swipe 多（>5）时这是最快的方式 |
| "ST 当前"标记 | 数字下方一个 3px 小圆点，表示 ST 聊天里该楼此刻采用的是这个 swipe。阅读器默认打开时就显示这个 swipe |
| 已收藏 swipe | 数字右上角一个极小的实心星 `fa-star`；小列表里对应行也有星 |
| 批注计数 | 若其他 swipe 上有划线，小列表对应行右侧显示 `✎3` |
| 切换效果 | 正文与思维链一起交叉淡化 120 ms；楼层高度变化时，保持**名字行在屏幕上的位置不动**（避免阅读位置跳走） |
| 记忆 | 阅读器记住每一楼"我最后看的是第几个 swipe"（存扩展存储），下次打开沿用；**永不写回聊天** |

**只读保证（人类可验收）**：在阅读器里把第 5 楼切到 3/5 → 退出阅读器 → ST 原聊天第 5 楼仍是原来那个 swipe。**[F1b][NF1]**

### 5.2 每个 swipe 自带思维链

```
切到 swipe 1/3：                    切到 swipe 2/3：                  切到 swipe 3/3：
爱丽丝          ◂ 1/3 ▸            爱丽丝          ◂ 2/3 ▸          爱丽丝          ◂ 3/3 ▸
▸ 思考了 12 秒                     ▸ 思考了 4 秒                    （没有思考行）
  雨还在下……                         雨停了……                         她没有回答……
```

| 规则 | 说明 |
|---|---|
| 各自独立 | 每个 swipe 显示**它自己的**思维链与"思考了 N 秒"（N 取该 swipe 自己的时长）。该 swipe 没有思维链 → 整行不出现，不显示空框，也不借用别的 swipe 的 |
| 时长未知 | 有思维链但无时长 → 写"思考过程" |
| 默认折叠 | 折叠态只有一行：`fa-chevron-right` + "思考了 12 秒"，颜色比正文淡 |
| 展开态 | 箭头转成向下；思维链正文以小一号字、左侧 2px 竖线（边框色）缩进显示；底部有"收起"小字，长思维链读完不用滚回去 |
| 切换 swipe 时 | 折叠/展开状态**按楼记忆**：本楼展开着 → 切到别的 swipe 也展开（若该 swipe 有思维链）。符合"我正在看这楼的思考过程"的意图 |
| 全部展开 | 设置条"思维链全部展开"打开时，所有楼所有 swipe 一律展开；关闭时一律折叠（清掉逐楼记忆） |
| 划线 | 思维链里的文字也能划线、批注、生成卡片；批注列表里标注"（思维链）" **[F7]** |
| DOM | 使用 ST 原生结构 `.mes_reasoning_details > .mes_reasoning_summary`，正文 `.mes_reasoning`，所以用户美化对思维链同样生效 |

从楼层工具条 `🖼` 或选中浮层"卡片"进入。覆盖在阅读器之上的全屏层，关掉回到原阅读位置。

- **选段**：来自选区（可跨楼）或整楼。跨楼时每楼一个名字行 + 正文段；中间省略的楼不出现。
- **临时屏蔽**：鼠标悬停预览里的词会出现虚线框；点一下就遮住，再点取消。按住拖可一次遮一串字。临时屏蔽只对这张卡生效；被遮的词旁出现小 `+`，点它"加入永久屏蔽词"。**[F2a]**
- **永久屏蔽词**：折叠列表，词条是小标签，可删除、可添加；与阅读器"屏蔽此词"是同一张表。**只影响卡片**。
- **屏蔽词 vs 替换规则**：屏蔽词 = "统一用当前遮盖样式盖住"；替换规则 = "这个词固定换成某个文字或某个小图案"（§6.4）。同一个词两边都有时，替换规则优先。
- **导出**：点"导出 PNG"→ 按钮变转圈 → 文件进浏览器下载目录，文件名 `st-reader-card-20260928-2104.png`。**[F2]**
- **正文美化随卡导出（T73）**：正则美化出的楼内样式、背景图在 PNG 里与预览一致。网上的背景图能取到就嵌进 PNG，取不到的地方显示浅色斜纹占位，右侧栏底部出现"提示：有背景图拿不到……"（和字体提示放在一起，前缀统一为"提示："）。
- **预览与导出不一致？（T73）**：预览下方、操作提示下面一行小字链接，点开就地展开说明：导出在隔离副本里重画，背景图的处理方式，动画只留静止一帧，没有字体文件的字体会换成系统字体。展开后有一个"复制诊断信息"按钮，复制版本、模板、尺寸、遮盖样式、楼层数、带楼内样式的楼数和上次导出的提示，**不含任何聊天内容**；复制后弹出提示条"已复制诊断信息（不含聊天内容）"。
- 卡片上**默认不放头像、不放角色真名、不放聊天文件名**；底部署名默认"ST Reader"，可改成任意文字或关掉。

### 6.2 四套模板

| 模板 | 描述 | 用色 | 字体 |
|---|---|---|---|
| **继承主题**（默认） | 就是用户在 ST 里看到的样子被"裱"起来：卡片底 = 主题聊天底色（不透明化，去掉模糊），正文色、引号色、斜体色取主题变量；四周 48px 留白，1px 主题边框，圆角 16px。用户换什么主题，卡片就长什么样 | 全部取 `--SmartTheme*` 变量 | 用户正文字体（含 Ny-font-manager 字体） |
| **纸张** | 像一页从书里撕下的纸：暖白底（约 `#f5f0e6`），墨色字（约 `#2a2521`），顶部与底部各一条细墨线，名字行用小号字距加宽的字，引号内对白用暗红（约 `#8a3a2e`），正文首行缩进两字，段间距大；右下角小号"— ST Reader"像页脚 | 固定配色，不随主题 | 用户正文字体（不另下载字体）；无衬线字体下也成立 |
| **深色** | 适合夜读截图：近黑底（约 `#141518`），暖灰白字（约 `#e4e0d8`），强调色取主题引号色并降低饱和度，名字行前一个小色点；四周无边框，留白更大，整体像深色电子书 | 固定底色 + 取主题一个强调色 | 用户正文字体 |
| **书摘**（仿微信读书，人类第一轮新增） | 模仿读书 App 的"书摘分享图"：浅灰底（约 `#f2f3f5`）上一张白色圆角卡（约 `#ffffff`，圆角 12px，极淡阴影）。卡片左上角一个大号淡色引号 `fa-quote-left`；中间是摘录正文，字号稍大、行距宽、深灰字（约 `#1f2329`），**不显示名字行**（像书摘只摘句子）；若这段文字有你写的批注，下方分隔线后加一块浅灰底的"**我的想法**"，放批注原文（正好对应阅读器的划线 + 批注）。底部一行"摘自《聊天标题》· char"（标题可改、可关，默认"一段故事"，不泄露真实文件名），左侧一个小方块"封面"——默认是强调色方块上写标题第一个字，也可换成你导入的图片；右下角小字"ST Reader 书摘"。强调色约 `#1b88ee` 蓝 | 固定配色，强调色可在"蓝 / 跟随主题"间切换 | 用户正文字体 |

> 书摘模板只模仿版式与气质，**不使用**微信读书的名称、logo、二维码或任何素材；卡片上不出现"微信读书"字样。

四套都满足：文字至少 4.5:1 对比度；尺寸三档（竖版 1080×1350 起可自动增高、方形 1080×1080、宽版 1600×900，内容多时竖版自动变长而不是缩字）。

### 6.3 三种遮盖样式 **[F2a]**

共同铁律：**被遮的字在生成的卡片里根本不存在**——不是把字模糊、也不是在字上面盖一块，而是把那段文字替换成遮盖元素，所以放大、调亮度、拖出文字都还原不了。

| 样式 | 样子 | 说明 |
|---|---|---|
| **涂黑** | 一条实心黑色（深色模板上为白色）直角长条，**高度 = 字高**（1em；T42 先做成行高，人类验收后定为字高，原为字高 80%），与汉字字身上下齐平 | 最像"机密文件"，最不容易误读 |
| **色块** | 一块圆角方块，高度同涂黑。颜色默认跟随模板强调色（继承主题 = 引号色、纸张 = 暗红、深色 = 柔和强调色）；T42 起可选 8 个预设或自己输入色号，也可以给单个词单独选色 | 更柔和，和卡片配色一体 |
| **小图案** | 一串 2–3 个小图标，颜色取强调色（也可用上面同一个颜色选择条换色）。图案来源二选一：①内置 Font Awesome 图标（`fa-star` / `fa-heart` / `fa-cat` / `fa-cloud` 等）；②**你自己导入的图片**（§6.5） | 可爱、适合轻松内容；内置图标是字体图标，不需要额外素材 |

**颜色选择条**（T42，替换文字底色与色块共用）：第一格"跟随 / 不加"（斜线圆点；跟随时画成跟随的颜色）+ 8 个预设圆点（樱粉、杏橙、柠黄、薄荷、天青、丁香、灰岩、夜蓝）+ 下一行"自定义"：彩色圆点点开调色盘，旁边色号框输入 `#f5b8c8` 或 `f5b8c8`、回车生效。只产出六位色号（core 只收 `#RRGGBB`）。

**长度也不泄密**：默认"统一长度"开启——无论被遮的是 2 个字还是 8 个字，遮盖都显示为固定约 3 字宽；关闭后按原词**实际渲染宽度**（像素测量，英文词也等宽，F14④）。测量在 1:1、已排版、字体就绪的卡片上做，量完才缩放放进预览（06 I026）。

### 6.4 名字替换 **[F2a]**（按人类第一轮反馈重写）

两个独立开关（T42 接 06 I021），每次打开工作台都是**开**：
- **自动名字**：第一层（char / user / 群成员）。关掉 = 角色名和你的名字原样显示，列表顶上写一行提醒。
- **我的规则**：第二层。关掉 = 不执行你的规则。
- 可以只关自动名字、保留"灯塔 → 某地"这类规则；两个都关时列表写"卡片上会显示真名和原词"。

**第一层：自动规则（不用设置）**

| 谁 | 替换成 | 说明 |
|---|---|---|
| `{{char}}`（单聊里的那个角色） | `char` | 取该聊天 header 的角色名 |
| `{{user}}` / persona 名 | `user` | 取该聊天 header 的用户名 |
| 群聊成员 | `char1`、`char2`…… | 按群成员列表顺序编号（群成员是明确可识别的）；可被第二层覆盖 |

**第二层：我的替换规则（永久保存）**

自动规则认不出的——单聊里出现的其他人物、昵称、地名、固定关键词——由用户自己定。规则**不是临时设置**：保存在扩展存储里，下次做卡片自动生效，也随导出 JSON 一起备份。

```
┌─ 管理替换规则 ─────────────────────────────────────────────┐
│ 原词          替换为                        作用范围         │
│ 鲍勃          [文字 ▾] 路人甲                 全部聊天   🗑  │
│ 小咪          [图案 ▾] 🐱（内置 fa-cat）      仅爱丽丝   🗑  │
│ 雨夜旅店      [图案 ▾] 🖼（我导入的"猫爪"）   全部聊天   🗑  │
│ 爱丽丝        [文字 ▾] 阿丽                   仅爱丽丝   🗑  │ ← 也可以覆盖自动规则
│ [+ 添加规则]                                                │
│ 区分大小写 ○    整词匹配 ●                                  │
└──────────────────────────────────────────────────────────┘
```

| 细节 | 规则 |
|---|---|
| 替换为 | **文字**（任意文字，如"路人甲""char2"）或 **图案**（内置 Font Awesome 图标，或你导入的图片，§6.5）。图案在卡片里显示为与文字等高的小图标。文字可选**底色**（T42：颜色选择条，默认不加）；加了底色时字色自动换成深字或白字保证看得清 |
| 作用范围 | "全部聊天"或"仅某角色的聊天"（在哪个角色的聊天里添加，就默认"仅该角色"，可改） |
| 优先级 | 我的规则 > 自动规则（但不能拆开自动名字） > 屏蔽词；长词优先于短词（"爱丽丝小姐"先于"爱丽丝"） |
| 添加入口 | ①这里的 `+ 添加规则`；②卡片预览里点一个词 → 小菜单多一项"总是替换为…"；③阅读器选中浮层"屏蔽 ▾ → 设为替换词…"（§1.5） |
| 映射预览 | 工作台右侧"名字替换"下实时列出**本卡片实际命中**的映射，标明"自动"或"我的规则"，一眼确认没漏。有规则因为"不能拆开名字"在名字里没生效时，底下一行黄字列出它们 |
| 只读 | 规则只作用于卡片的文本副本（03 §4.4），不影响阅读器正文，更不影响聊天 |

### 6.5 导入自己的小图案 **[F2a]**（人类第一轮新增）

- 位置：卡片工作台 → 遮盖样式选"小图案"时，下方出现图案选择条：先是内置图标，最后一格 `+ 导入图片`；替换规则里选"图案"时是同一个选择条。
- 支持 PNG / JPG / WebP / SVG（SVG 导入时清除脚本等危险内容），单张 ≤ 200 KB，最多 30 张；超出时提示"图片太大，请换一张小一点的"。建议方形、透明底。
- 导入的图片存在扩展自己的浏览器存储里（与批注同处），**随"导出 JSON"一起备份**，导入 JSON 时一起恢复。
- 每张可改名、可删除（删除前提示"有 N 条替换规则在用它"）。
- 图片只由用户从自己电脑选择，扩展不联网下载任何素材（符合 NF3 与磁盘铁律）。

## §7 视觉方向 A / B —— **已定：B 为主，A 作为可选排版**

两个方向**功能完全一样**，区别在"楼层长什么样、界面有多安静"。

> **人类决定（2026-09-28）**：B 优先；A 若工作量不大也做。
> 落地方式：阅读器默认用 **B「原样」**。A「书页」作为设置条 `⋯ → 排版：原样 / 书页` 的可选项，T21 里只写一层作用域样式（`#stcr_root.stcr-dir-a`），不改结构；若做下来工作量大（例如要逐个适配美化外框），就先不显示该选项，并把 A 移入 `01` 的"v2 候选"。
> 下方两段描述与差异表保留，作为两种排版的定义。

### 方向 A · 「书页」

像一本排好版的小说。阅读器在楼层上加一层书页排版：**不显示头像，弱化楼层外框**（气泡背景、边框变得很淡或去掉），楼层之间用一条细线或一个小小的 `✦` 分隔；名字行变成正文上方一行小字；正文首行缩进、段落间距加大；用户楼颜色稍淡，读起来像"对白 + 旁白"。主题颜色、字体、美化正则的产物（比如彩色对白、状态栏）**照样生效**，只是楼层外面那层"聊天框"被压平。界面外框极安静：顶栏鼠标不动 2 秒就消失，只剩字。

适合：真正想"读小说"、一读就是几百楼的时候。

### 方向 B · 「原样」

像一个更好用的 ST 聊天窗口。楼层**完全保留 ST 里的样子**：头像、气泡、用户美化 CSS 做的外框和装饰全部原样；阅读器只是在外面加上抽屉、工具条、设置条，把"编辑/删除/重新生成"这些按钮换成"收藏/思维链/复制/卡片"。顶栏常驻不消失，工具更显眼。

适合：美化做得很重、希望在阅读器里看到和 ST 一模一样画面的时候。

### 关键差异

| 项 | A 书页 | B 原样 |
|---|---|---|
| 头像 | 不显示 | 显示（与 ST 一致） |
| 楼层外框 / 气泡 | 压平成淡背景或无背景 | 完全保留 ST 与美化 CSS 的样子 |
| 楼层分隔 | 细线或 `✦` | 气泡本身的间距 |
| 首行缩进、段距 | 有（可在设置里关） | 无（跟 ST 一样） |
| 用户楼 | 字色稍淡、无框，像对白 | 与 ST 一样（通常是另一种气泡色） |
| 美化 CSS 命中 | 颜色、字体、正文内装饰全命中；楼层外框类装饰被压平 | 100% 命中 |
| 顶栏 | 鼠标静止 2 秒自动隐藏 | 常驻 |
| 楼层工具条 | 悬停才出现 | 悬停出现，并且名字行右侧常驻一个淡淡的 `⋯` |
| 默认阅读模式 | 分页 | 滚动 |
| 默认正文宽度 | 680 px（约每行 34 个汉字） | 跟随 ST 聊天宽度 |
| 卡片默认模板 | 纸张 | 继承主题 |
| 整体感觉 | 电子书阅读器 | ST 聊天窗口的"只读增强版" |

> 第一轮我建议 A，人类选了 B 优先。§3 线框图里楼层没画头像只是为了图简洁；按 B，楼层会带头像与 ST 原样气泡。
> 切换排版时，"默认阅读模式、默认宽度、卡片默认模板"只在用户**没手动改过**时跟着变。

## §10 HTML 楼层 **[F10][F10a][F10b][D15][D22]**

**认哪些**：完全按 core 的 `detectHtmlBlocks`（03 §5.13）——围栏代码里有真正的 `<body>`，或整楼就是一份 HTML 文档。别的代码块照旧是代码块。

**楼里的样子**（原来的代码 / 正文留在原位只是藏起来，整块渲染区不计入划线锚点 → "渲染 / 原文"来回切，划线不受影响）：

```
</> HTML  [渲染|原文]  [手机|平板|桌面|跟随正文]            ⊕外链  🕵复制脱敏版  📷截图
┌──────────────────────────────── 浅底圆角框 ────────────────────────────────┐
│                     ┌──────── 沙箱 iframe（按选的宽度）────────┐             │
│                     │   模型写的网页 / 小游戏，能点、能滚      │             │
│                     └──────────── 高度自动跟着内容 ────────────┘             │
└──────────────────────────────────────────────────────────────────────────────┘
```

- 一条细工具条，字小、灰，不抢正文。"原文"时只剩 `</> HTML [渲染|原文]` 和复制 / 截图（划线在原文里做）。
- 宽度四档：手机 390 / 平板 768 / 桌面 1200 / 跟随正文。比正文栏宽时渲染区向两边伸出去，占到阅读区可用宽度（左右各留 16px）；还放不下就整块 `transform: scale()` 等比缩小到可用宽度，外框高度按缩小后的高度收紧，工具条右侧小字"已缩放 83%"。不裁切、不横向滚动；滚动与分页相同（D27、T52）。有 HTML 块的楼放开 ST 的 `.mes_block { overflow-x: hidden }`，否则伸出部分会被裁。最近选的一档记成默认（已显示的块不跟着变）。跟随正文会随窗口宽度重排（去抖）。
- 外观（T52）：渲染区没有外框和底色，iframe 透明（core T51），HTML 自己决定底色。
- 裸 HTML 只框住标签区间（D26、I038）：按 core 给的每一段的顶层标签序列，在排好版的正文里找到相连的那几个顶层元素收进"原文"容器，前后与段间散文留在正文里；同楼多段各有一条工具条。对不上（清洗或 Markdown 改了结构）时退回整楼一块。
- **正则之后识别（T75）**：
  - 在显示正则跑完的正文上找，所以正则改过的盒子、正则产出的整页网页也能单独框住。
  - 只装着一个 `<style>` 的段落算作那个 style（Markdown 会把单独一行的 `<html><head><style>` 包进段落）。
  - 原文里模型没写 HTML 时只框整页；普通正则美化（信纸、状态条）仍在正文里，和 ST 一样。
- **正文样式（T75）**：楼内 `<style>` 里的动画、图标字符（如 `content:"\f005"`）都保留，只去掉加载字体 / 样式表的规则和越出本楼范围的选择器，不再整段删除。
- 外链（D22）：默认允许（仅 HTTPS）。⊕ 亮 = 允许；点一下只对这一块断网，状态字显示"已断网"。Aa →"⋯"→ HTML 一行：**渲染 / 原文**（默认看哪种）+ **允许外链**开关；改了就清掉每一块自己的选择、全部按新默认重来。逐块的选择只在这次打开阅读器期间有效。
- 懒加载：离视口还有约一屏才建沙箱；换候选、翻页裁窗、切到原文、关阅读器都销毁沙箱（不留后台脚本）。首次高度前先占上次的高度，不跳。
- 渲染失败：框里一句"这段 HTML 没能渲染出来。[看原文] [再试一次]"。
- 脱敏显示开着（T45）：沙箱里跑的是换过词的 HTML（core `maskHtmlString`：只换文字，不碰标签、属性、脚本）。
- 代码块右上角两枚按钮：🕵 复制脱敏版（F10b）+ 复制。脱敏版：像 HTML 的走 `maskHtmlString`（原来是片段就只取回片段，不补 `<html>` 外壳），其余走 `maskCodeText`；屏蔽词按字数变 █、替换规则、自动名字（char / user）都做。

### 9.3 T23a 实现记录（2026-09-29）

- **入口三处**：楼层工具条最右 `fa-image`（整楼、当前显示的候选）；选中浮层"🖼 卡片"（跨楼时它是唯一亮着的按钮）；右侧面板每条划线右边的 `fa-image`（悬停出现）。面板"全部聊天"里别的聊天的划线也能直接做卡：工作台自己只读打开那个聊天，关掉时释放。
- **选段怎么变成卡片**（03 §5.9）：阅读器里的选区先换算成"每楼从第几个字到第几个字"（和划线同一套锚点文字），再在 core 的 `createCardMessage` 已替换名字的副本上按位置裁剪。名字换成 char/user 后长度变了，用逐字对齐换算位置；名字只选了一半也整个换成 char。裁剪出的片段是新节点、不绑定原文，导出用 `replaceNames:false`。看不见的楼（隐藏的用户楼）和收起的思维链不算进选区。
- **模板**：四套，"继承主题"的正文容器用 `#stcr_chat`，用户主题、美化 CSS、Ny 字体规则原样命中；纸张/深色/书摘把楼层压平成"小名字 + 正文"，字体取阅读器正文此刻的字体。默认模板跟排版：原样→继承主题，书页→纸张（§7）；用户点过就记住。
- **尺寸**：竖版 540×675 起（导出 ×2 = 1080×1350，内容多自动变长）、方形 540×540、宽版 800×450。预览按比例缩小放进舞台，导出按原尺寸。
- **遮盖**：永久屏蔽词 + 本卡临时词，一律用 core 的 `wrapMaskSpans` 把原字从副本里删掉换成遮盖元素。涂黑在深色模板上是白条；色块用模板强调色；小图案六个内置图标（UI 自己画成图片，见 06 I018）。"统一长度"开 = 3 字宽，关 = 按原字数。T45 验收后：关掉统一长度时，小图案**几个字就几个图案**、宽 = 个数 × 1 字宽（core 固定画 3 个，UI 在副本上补齐或删掉，`fitStickerCounts`）。
- **点词**：鼠标悬停出现虚线框（中文按浏览器词典分词，标点不算）；点一下临时遮住，再点取消；拖选一串一次遮住（≤40 字）；临时遮住的旁边出 `+`，点它加入永久屏蔽词。右侧"临时遮住"列表也能 +/×。点永久屏蔽词的遮盖只提示去右边删，防止误点。
