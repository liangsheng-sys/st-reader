【ST Reader】只读聊天阅读器丨楼内随意切 swipe丨划线批注丨一键打码做分享卡丨HTML 小剧场可调宽截图

在酒馆上再套一个阅读器，听起来有点脱裤子放屁。但我自己用下来，它解决的是三件酒馆本身不管的事：

> 重 roll 爱好者福音：同一层里有好几个舍不得删的回复？在阅读器里随意切换 swipe，还能单独收藏某一个。
> 像真的小说阅读器那样划线、写批注、收藏，**完全不碰你的聊天文件**。
> 不好意思分享聊天记录？一键打码，顺手生成一张好看的卡片。

# 安装
【扩展】-【安装扩展程序】，粘贴这个地址，分支留空：
`https://github.com/liangsheng-sys/st-reader`
装好刷新页面，顶栏多一个书本图标，点它就进阅读器。也可以在魔杖菜单里找「阅读器」，或输入 `/reader`。

# 它能干什么
## 📖 读
- 最近 / 按角色 / 收藏 / 当前聊天四个入口，单聊群聊都行，翻页或滚动随你
- 思维链默认折叠，不想看可以整行隐藏
- 楼内 `◂ 2/5 ▸` 切 swipe，每个 swipe 自带自己的思维链。退出阅读器，酒馆里的候选一个字都不变

## ✏️ 记
- 四色划线、写批注、收藏整个聊天 / 某一楼 / 某个 swipe
- 批注面板能看本聊天或全部聊天，点一下跳回去
- 一键导出 JSON 备份，换浏览器也不丢

## 🎴 分享
- 跨楼选段生成卡片，四套模板（跟随你的主题 / 纸张 / 深色 / 书摘风）
- 屏蔽词永久保存，卡片上点哪个词就遮哪个；涂黑、色块、小图案三种遮法，可以自己导入小图片
- 名字替换：角色自动变 char、你自动变 user，其他人名自己定规则
- 「脱敏显示」开关：直接在阅读器里看替换后的效果

## 🧩 HTML 小剧场
- 模型生成的手机界面、网页小游戏直接在阅读器里渲染，**不需要酒馆助手**
- 手机 / 平板 / 桌面 / 跟随正文四档宽度，不再被聊天栏憋着
- 相机按钮截当前画面，带屏蔽词，可以框选只截一部分；还有「复制脱敏版」代码按钮

## 🎨 跟你的酒馆长一样
- 复用你的酒馆主题、自定义 CSS、显示正则，不用在阅读器里再设一遍
- 支持奈亚大佬的『Ny-字体管理器』https://discord.com/channels/1134557553011998840/1468997478245335100
- 代码块高亮和复制

# 几句实话
- 聊天文件只读。不保存、不改、不删、不改候选序号。
- 不收集任何信息，没有统计、没有云端。批注收藏都在你自己浏览器里。
- 外链：扩展自己不请求任何第三方域名。唯一会联网的是你聊天里模型写的 HTML（它引用的图片字体等），默认允许，Aa 里能整体关掉，也能单独给某一块断网。
- 50 MB 级别的超长聊天能打开，首次打开偶尔要三秒多。
- 源码公开，AGPL-3.0。
