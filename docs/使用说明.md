# ST Reader 使用说明

ST Reader 是 SillyTavern 里的一个阅读器：像读小说一样读聊天记录，还能划线、写批注、收藏，把喜欢的段落做成分享图片。**它只读不写**：不会改动你的聊天、候选和角色，你在阅读器里做的一切都只存在阅读器自己那里。

## 怎么打开

三种方式任选：点 ST 顶栏的**书本图标**；点输入框左边的**魔杖菜单 → 阅读器**；或者在输入框里输入 `/reader` 回车。

打开后默认显示 ST 当前的聊天，并停在你上次读到的地方。想读别的聊天，点左上角 **≡** 打开抽屉，分"最近 / 按角色 / 收藏 / 当前"四栏；"按角色"可以搜名字、按标签筛选。点右上角 **✕** 或按 Esc 回到 ST。

## 读

- **翻页**：滚轮或方向键滚动；也可以换成分页模式，像翻书一样一页一页翻。
- **换候选**：某一楼有多个候选时，名字行右边有 ◂ 2/5 ▸，点箭头切换，点中间的数字看全部候选。这只改变阅读器里显示哪一个，ST 里采用的不变（数字下面的小圆点表示 ST 当前用的那个）。
- **上一楼 / 下一楼**：正文列右边有一枚竖着的小胶囊，写着你正在读的这一楼是谁说的；多候选的楼，名字下面直接有 ‹ 2/5 ›，点箭头就换候选。鼠标移上去（手机上点一下名字）展开：↑ 上一楼、⤒ 回到这一楼开头、↓ 下一楼、收藏。键盘上 [ ] 也是上一楼 / 下一楼。想让这几个按钮一直露着，到 Aa → 显示 打开"胶囊默认展开"；胶囊想放左边，在同一行"楼层胶囊"选"左"。
- **思维链**：点"思考了 x 秒"展开或收起。
- **跳楼**：点底部的进度（"第 1–30 楼"那一行），输入楼号。
- **调整外观**：点右下角 **Aa**，能改翻页方式、字号、行距、正文宽度、思维链折叠或隐藏、隐藏你自己说的话；"隐藏 ST 已隐藏的楼"会把你在 ST 里点过小眼睛的楼（你说的和角色说的都算）收成一行，点开能看。被隐藏过的楼平时照常显示，名字旁有个淡色"已隐藏"小标签。正文宽度默认和 ST 聊天栏一样宽。点 Aa 里的 **⋯** 还有更多：HTML、排版（"原样"和 ST 一样；"书页"压平聊天框，更像小说）、备份、版本。

## 记：划线、批注、收藏

- **划线**：选中一段文字，弹出小条，点一个颜色就划好了。点已有的划线可以换颜色、写批注或删掉。
- **批注**：选中文字后点"批注"，写下想法，点外面或按 Ctrl+Enter 保存。有批注的地方会出现一个小标记，点它看内容。
- **收藏**：鼠标移到某一楼，名字行会出现小工具：书签图标收藏整楼，星星收藏当前这个候选。顶栏的星星收藏整个聊天，以后在抽屉的"收藏"栏里找。
- **找回来**：点右上角的荧光笔图标，打开"划线、批注与收藏"面板，可以看本聊天或全部聊天，点一条就跳过去。如果原文后来被改掉、找不到对应位置，这条会出现在"孤立"一栏，内容不会丢。

## 分享：卡片与脱敏

- **做卡片**：选中一段文字（可以跨好几楼）点"卡片"，或者在某楼的小工具里点图片图标。会打开卡片工作台：左边是预览，右边是设置。
- **模板**：继承主题（用你现在的 ST 配色和字体）、纸张、深色、书摘；尺寸有竖版、方形、宽版。设好后点"导出 PNG"保存图片。
- **遮住不想给人看的词**：三种样子可选——涂黑、色块、小图案，被遮的字完全看不出来。
  - 一次性的：在预览里点一下那个词，就只在这张卡上遮住。
  - 永久的：选中文字后点"屏蔽"，以后所有卡片都会遮住它。
  - 换成别的词：点"屏蔽"旁边的小箭头 → 设为替换词，比如把真名换成代号。
  - "自动名字"会把角色名和你的名字自动换掉，可以单独关掉。
- **脱敏阅读**：Aa 里"脱敏"一行打开"脱敏显示"，正文直接按屏蔽词和替换规则显示，适合截图或给别人看屏幕。顶栏会出现"脱敏中"提醒，点它就关掉。
- **自动名字**：Aa"脱敏"一行的开关，默认开：角色名和你的名字换成 char / user。脱敏显示、复制脱敏版代码都按它来；做卡片、HTML 截图时也先按它，窗口里还能临时关掉。
- **管理屏蔽词与替换规则**：Aa"脱敏"一行的按钮，一处看全、增删屏蔽词和替换规则。一条规则可以有好几个原词：在"更多原词"里一行写一个，比如"灯塔"再加"灯台"，两个都会换成"某地"。

## HTML 小剧场

模型写的网页、小游戏、手机界面会直接显示出来，可以点、可以玩，而且被关在一个安全的小窗里，碰不到你的 ST。每块上面有一条工具条：

- **渲染 / 原文**：在效果和代码之间切换。划线在原文里做。
- **手机 / 平板 / 桌面 / 跟随正文**：换显示宽度。比正文宽时会向两边伸出去；窗口还是放不下，就整块等比缩小，旁边显示"已缩放 xx%"。
- **地球图标**：这一块能否加载网上的字体和图片。想全部断网，在 Aa → ⋯ 里关掉"允许外链"。
- **面具图标**：复制一份把屏蔽词、名字都换好的代码。
- **相机图标**：截图分享。可以选"当前画面"（你玩到的进度）或"初始画面"，可以拼成长图，也可以在图上拖一个框只截一部分。

嫌工具条碍眼：Aa → 显示 → 打开"隐藏 HTML 工具条"。之后工具条平时不出现，鼠标移到那块 HTML 上才浮出来；手机上点块右上角的小 ⋯。

## 设置与备份

你的划线、批注、收藏、屏蔽词、替换规则和阅读设置**会自动备份到你自己的 ST 里**，不用操心：

- **什么时候备份**：每次改动后约 3 秒自动写一次；关阅读器、关网页时立刻写。位置是 ST 的 `data/<你的用户名>/user/files/st-reader-backup.json`（不在 chats 目录，不碰聊天）。每天第一次还会另存一份带日期的，例如 `st-reader-backup-20261021.json`，只留最近 7 天。
- **在哪看**：Aa → ⋯ → "备份"。第一行写着"上次自动备份：10-21 09:30 · 1.2 MB"；没备份成功时这里会说原因（例如"ST 文件接口不可用"），Aa 按钮上也会亮一个小点。
- **清了浏览器数据 / 换了浏览器**：只要还是同一个 ST，下次打开就会自动合并回来，打开阅读器时提示"已从 ST 服务器恢复批注 N 条"。合并只补上缺的、同一条以较新的为准，不会删你现有的。
- **两个按钮**："立即备份"马上写一次；"从服务器恢复"手动合并一次（同样不删现有的）。
- **导出 / 导入 JSON** 照旧保留：想把数据带到另一个 ST 或自己另存一份，点"导出 JSON"（下载到浏览器的下载文件夹）；在新地方点"导入 JSON"选这个文件。
- **没有第三方云**。想异地保存，备份你 ST 的 data 文件夹就行。

"更新后提醒"开关和"已经看过哪个版本的更新说明"也记在 ST 自己的设置里，清浏览器数据后不会再重复弹"更新了什么"。

**版本与更新**：Aa → ⋯ 最上面一行显示当前版本。点"检查更新"会让 ST 去 GitHub 看有没有新版本；有的话点"立即更新"，完成后点"刷新页面"。更新后第一次打开阅读器，会告诉你这次改了什么，不想看可以勾"以后更新不再提醒"。

## 常见问题

**明明更新了，怎么还是旧版？是不是装了两份？** 如果以前用目录联接装过，先双击 `install/unlink-from-my-st.cmd`，再到 ST 的“安装扩展”里粘贴仓库 URL 安装。两份并存会加载旧副本，正式使用只留 URL 安装的那份；清理后重启 ST，再刷新页面。

**阅读器里的样子和 ST 不太一样？** 阅读器会沿用你的主题和自定义样式，但聊天框之外的布局是阅读器自己的。想更像小说，试试 Aa → ⋯ → 排版"书页"。

**我的划线不见了？** 先看面板里的"孤立"一栏：原文被编辑、删除或换了候选时，划线会暂时放在这里。

**会不会改掉我的聊天？** 不会。阅读器只读取聊天，所有记录都只存在阅读器自己那里。

**打开很长的聊天有点慢？** 第一次打开要从 ST 读取整个聊天，几十 MB 的聊天可能要等几秒。

**快捷键**：← → 或空格翻页；[ ] 上一楼 / 下一楼；, . 换候选；R 展开思维链；B 收藏这一楼；G 跳楼；\ 开关抽屉；/ 开关划线面板；Esc 逐层关闭。在输入框里打字时快捷键不起作用。
