|---|---|---|---|---|---|

## 结论
没有现成项目覆盖"楼内切换 swipe + 思维链折叠 + 脱敏卡片 + ST 正则/美化原样生效 + 批注收藏"。做 ST UI 扩展（D01）能白拿主题、字体、正则引擎、markdown 管线与只读 API，成本最低。
