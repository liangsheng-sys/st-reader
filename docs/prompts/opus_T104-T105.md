## T104 卡片模板升级与自制模板（D49、F22）

人类原话："需要 opus 自己灵活学习以下项目的优点来改进已有的分享卡片，并允许用户自制和导入分享卡片模板。" 五个项目：https://zhuanlan.zhihu.com/p/669011394 、https://github.com/weirui88888/text2image-gui 、https://github.com/weirui88888/anyphoto 、https://github.com/qiaoshouqing/text2card 、https://github.com/ygh3279799773/streamer-card 。规划者能打开的只有三个 README，要点已写在 `docs/research/参考项目对比.md` 末节；你若能打开知乎那篇与 text2image.fun，自己再看一眼，**只学版式与气质，不抄代码、不用它们的素材**。

它们共同的好看之处：一张卡 = 页眉（小图标 + 标题 + 日期）+ 按语 + 正文（编辑感的中文字体、宽行距、够大的内边距）+ 页脚（作者 / 字数 / 水印），配色是几十组精选的浅色渐变与深色，用户只选不调。我们的差别：正文是 RP 对话（有名字行、有引号色、可能带正则美化），而且**要脱敏**、**不能放头像真名**、**不下载字体**。

要做：
1. **右栏重排**成五组可折叠区：模板 / 配色 / 排版 / 页眉页脚 / 遮盖与名字，默认只展开"模板"与"遮盖与名字"（现有的屏蔽词、名字替换、小图案都归这组）。手机档改为上下堆叠、预览在上。
2. **新控件**（都存进 `stcr:ui:card:v1` 的 prefs，并成为"模板"的一部分）：
   - 页眉：开关；图标（Font Awesome 里挑 8–12 枚适合故事的：羽毛笔、书、月亮、星、茶杯、剧场面具…）；标题（默认空，占位"一段故事"）；日期开关（用选段第一楼的日期，格式 `2026年11月16日`）。
   - 按语：一行文字，默认关。
   - 页脚：署名已有；加"日期"、"字数"（正文字数，去遮盖）两个开关；"ST Reader" 字样跟署名走，署名清空则不显示。
   - 排版：字号档（小 / 中 / 大，对应现在的 1.0 / 1.12 / 1.25 倍）、行距（1.6 / 1.8 / 2.0）、字距（0 / 0.02em / 0.05em）、对齐（左 / 两端）、内边距（紧 / 标准 / 宽）、圆角（0 / 12 / 24）。
   - 配色：≥ 16 组预设，浅深各半，含双色渐变（角度固定几档）；每组给出底色、正文色、名字色、引号色、强调色；字色按底色亮度自动在深 / 浅两套里选并保证 4.5:1（你已有 `readableOn`）。另加"自定义"：两个颜色输入 + 角度，用现有 `colorPicker`。
   - 纹理：无 / 格纹 / 点阵 / 横线，纯 CSS（`repeating-linear-gradient` / `radial-gradient`），颜色取正文色的 6–10% 透明度。
   - 字体族：跟随正文（默认，含 Ny 字体）/ 系统衬线（`"Noto Serif CJK SC", "Source Han Serif SC", "Songti SC", SimSun, serif`）/ 系统无衬线 / 系统楷体（`KaiTi, "Kaiti SC", STKaiti, serif`）；只写族名，没装就回退。
3. **四套内置模板**改成"预设 = 一组上面选项的值"（继承主题 / 纸张 / 深色 / 书摘），外观与现在一致：T73 的预览 vs 导出像素对照继续通过，再加一组"改造前后四套模板各一张截图"的对照（允许 ≤ 1% 像素差，差在抗锯齿）。"继承主题"仍跟 ST 主题，不跟阅读器的纸张 / 夜读主题。
4. **自制模板**：工作台顶部"另存为模板…"（起名，≤ 20 字）；模板行内置四套之后显示自制的，长按 / 右键或 ⋯ 弹"重命名 / 设为默认 / 导出 / 删除"；"设为默认"决定下次打开工作台用哪套。
5. **模板文件**：JSON
   ```json
   { "format": "stcr-card-template", "version": 1, "name": "…", "base": "paper", "options": { … }, "css": "" }
   ```
   导出：下载 `.json` + "复制为文本"；导入：选文件 + 粘贴文本两种。校验：`format`/`version` 不对、`options` 里有未知键或越界值 → 拒绝并说明哪一项。`css` 可选，给高手写附加样式：用 T75 的 `cleanStyleText`（在 `src/core/formatter.js` 或 `cssDeclarations.js`，按 03 找）逐条清洗——去 `@import`、`@font-face`、外链 `url(`（只留 `data:`）、`position:fixed`、`expression`；每条选择器强制加前缀 `.stcr-card[data-tpl="<模板id>"]`，不许出现 `#stcr_root`、`body`、`html` 等卡片外选择器；超过 8 KB 或清洗后为空 → 拒绝整份并说明。导入成功后在模板行出现，缩略色块按它的底色画。
6. **存储**：`store.settings` 键 `stcr:ui:card:templates:v1`（数组，≤ 30 个，每个序列化 ≤ 20 KB；背景图若要支持，只允许引用现有"导入小图案"素材库的 `asset` id，不另存图）。随备份 JSON 走（`store.settings` 本来就在 `exportAll` 里）；备份格式 `version` 仍为 1。
7. **测试**：`ui.test.js` 覆盖模板 JSON 校验（好 / 坏各 ≥ 6 例）、CSS 清洗与前缀、预设与现有四套的等价；浏览器自测：自制模板导出 PNG 与预览一致、导入含外链 `url(` 的被拒。
8. **文档**：02 §6.2 改为"内置四套 + 自制模板"，加模板文件格式；使用说明"分享"一节加"自己做一套模板"与"导入别人的模板"两段，口吻给小白。

人类验收步骤要写到：双击打开 8100 → 选一段 → 分享卡片 → 配色挑一组渐变、开页眉选个图标写标题 → 另存为模板"我的" → 关掉再开，模板行里有"我的" → 导出 PNG 与预览一样 → 导出 JSON → 删掉"我的" → 粘贴导入 → 回来了。

## T105 番外视图 UI（D48、F21）

等 T103 合入 main 后开工。先读 03 §5.23（astra 的合同：规则对象、`classifySideStory`、`locateSegments`、推荐做法、存储键）。人类原话见 D48 的理由栏；三类用户：模型随正文附小剧场（标签）、用户发"请暂停正文写个番外"（关键词，user 楼 + char 楼一起拎）、自己手动隐藏过的（隐藏楼）。**让用户自己选自己的方式**，可以同时开。

要做：
1. **Aa → 新增"番外"区**：三行开关各带编辑——标签（开始 / 结束两个输入框，或切到"正则"填一条；下面小字示例 `<小剧场>` `</小剧场>`、`<details><summary>番外`、`</details>`；勾选"在正则美化之后的正文里找"对应 `scanRendered`）；关键词（标签式多词输入，预填候选五个词，可删可加）；隐藏楼（一个开关，说明"ST 里点过小眼睛的楼算番外"）。最下一行"这个聊天不分番外"（每聊天开关，存 §5.23 给的键）。规则存全局键，改动后当前聊天立即重算（关键词与隐藏法同步，标签法 `scanRendered` 时显示"正在找…"并分批）。
2. **顶栏三段切换"正文 / 番外 / 全部"**：只在当前聊天有命中时出现（没有番外就什么都不显示，不打扰）；快捷键 `V` 轮换（输入框聚焦时不抢；02 §4 登记）。默认视图"正文"；每聊天记住上次视图（瞬时键）。
3. **正文视图**：片段级番外用 `locateSegments` 的 Range 包进 `.stcr-side-part`，**不删节点**（划线锚点不变），显示为一条可点的淡色折叠条"番外 · 约 N 字 · 去番外看"（点击切到番外视图并滚到这一条）；对不上的（astra 返回 null）退回整楼处理。整楼级复用 `foldRuns` 的折叠条样式："— 番外 · N 楼 —"，点开切到番外视图那一楼。与现有"隐藏 ST 已隐藏的楼"开关的关系：隐藏法开着时，正文视图里它们走番外折叠条而不是原来的"— 已隐藏 · N 条 —"。
4. **番外视图**：只显示 `floors` 里的楼与有 `segments` 的楼；片段级的楼只露出片段，其余包进 `.stcr-side-part[hidden]`（同样不删节点）；每条顶上一行小标"第 N 楼 · 候选 2/5"，点它回正文视图并滚到那一楼。划线、收藏、卡片选段、脱敏在两个视图都照常；胶囊在番外视图里的"上一楼 / 下一楼"只在番外之间跳。
5. **阅读进度**：两个视图分开记（瞬时键，不触发备份）。
6. **导出对话框**：范围加"只正文 / 只番外"两个单选（传 `view` 与当前规则），对话框的"将导出 N 楼"计数跟着变。
7. **抽屉**（可选）：列表行若该聊天有番外，标题后一个小 `fa-masks-theater` 标记——只在列表已经算过的情况下显示，不为它额外读聊天。
8. **测试**：`ui.test.js` 覆盖视图切换的状态机与进度键；浏览器自测用 T103 的 fixture：正文视图 DOM 里小剧场文字全在 `[hidden]` 内、番外视图只露小剧场、点楼号回去、切视图后划线仍在原位、导出"只番外"TXT 只有小剧场。
9. **文档**：02 加"番外"一节（线框 + 三种规则的解释）、§4 加 `V`；使用说明加"把小剧场 / 番外单独拎出来"一节，用人类的三类用户举例。

人类验收步骤：8100 打开 fixture 番外聊天 → Aa → 番外 → 开"标签"（默认就是 `<小剧场>`）和"关键词" → 顶栏出现"正文 / 番外 / 全部" → 正文里小剧场变成折叠条 → 点"番外"只剩小剧场、每条带楼号 → 点楼号回正文 → ⋮ 导出为文档选"只番外"。
