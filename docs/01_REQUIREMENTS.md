# 01 · 需求清单

来源：人类 2026-09-28 的原始需求（`E:\自用阅读器plan.txt`），由规划者整理。验收即对照本表。

## 一句话
在 SillyTavern 里，像读小说一样读自己的聊天记录，并能把喜欢的段落做成好看的、脱敏的分享卡片。

## 功能需求
| ID | 需求 | 验收标准（人类可操作） |
|---|---|---|
| F1 | **阅读**：入口有"最近 / 按角色 / 收藏 / 当前聊天"四个；单聊 + 群聊；分页与滚动两种模式；字号、行距、正文宽度可调；可隐藏用户楼层 | 打开阅读器 → 选一段聊天 → 能像读书一样翻页 |
| F1a | 思维链**默认折叠**，单楼可展开，也有"全部展开/折叠"；与 ST 自己的 auto_expand 设置无关 | 楼层顶部"思考了 12 秒"可点开 |
| F1b | **楼内切换 swipe**（重点）：楼层有 `◂ 2/5 ▸`，每个 swipe 显示自己的正文与思维链；切换只影响阅读器视图，**不写聊天** | 切完退出，回 ST 原聊天，swipe 没变 |
| F2 | **选段 → 分享卡片**：可跨楼层自由选择文本；卡片样式默认继承当前主题色与字体，另附 ≥3 套模板；导出 PNG | 选一段 → 点"生成卡片" → 图片进下载目录 |
| F2a | **脱敏**：持久化屏蔽词表 + 卡片上点词临时屏蔽；名字替换开关（{{user}}/persona → user，角色 → char1/char2…）；遮盖样式：涂黑 / 主题色块 / 小图案 | 屏蔽词在卡片上不可辨认；原聊天不受影响 |
| F3 | **代码块渲染**：语法高亮 + 复制按钮 | 与 ST 主界面一致 |
| F4 | **ST 美化生效**：主题色、自定义 CSS、字号缩放、聊天宽度都作用于阅读器 | 切换 ST 主题，阅读器随之变化 |
| F5 | **Ny-font-manager 生效**：安装后它的字体 / 字号 / 颜色 / 对话字体规则在阅读器同样命中 | 开发实例里装该扩展验证 |
| F6 | **ST 正则生效**：全局 + 该聊天所属角色的作用域正则（含 `character_allowed_regex` 判断）+ 预设正则；只跑"显示"类（`markdownOnly` 或两项都不勾）；深度按该聊天计算；每条只跑一次 | fixture 里角色 A **未被选中**时读 A 的聊天，A 的美化正则仍生效 |
| F7 | **批注 / 备注 / 划线**：划线多色；批注可写文字；有批注列表可跳转；刷新页面、换主题、正则变化后仍能定位；失配的进"孤立"列表而不是丢失 | 划线后刷新页面仍在 |
| F8 | **收藏楼层**，并且能**收藏某一楼的某个 swipe**；收藏列表跨聊天汇总，点击直接跳到那一楼那一个 swipe | 收藏里能跳回那个 swipe |
| F9 | **布局简单明了**：左侧聊天列表抽屉、中间正文、悬浮楼层工具条、底部阅读设置条、选中文字浮层（划线 / 批注 / 生成卡片 / 屏蔽此词）；手机可用 | 人类一句话："找得到东西" |

## 非功能需求
| ID | 需求 |
|---|---|
| NF1 | **只读**：任何情况下不写、改、删、重命名聊天文件，不改 swipe_id，不改 chat_metadata |
| NF2 | 单个 50 MB 聊天能打开并翻页（分页渲染，不整篇渲染） |
| NF3 | 扩展业务只访问同源 `/api/*` 只读接口，无自有第三方服务或遥测；D22/D23 允许用户 HTML 外链与截图所需的展示资源读取 |
| NF4 | 扩展体积 < 3 MB，无 build 步骤，装上即用 |
| NF5 | 阅读器打开/关闭不影响 ST 主界面状态（不改当前角色、不改当前聊天） |

## 参考项目与它们缺什么
见 `research/参考项目对比.md`。结论：st-viewer 有正则/CSS/书签但要手动导出且无 swipe/思维链；ChatVault 有全局列表与沉浸阅读但是"摘取规则"而非 ST 正则、无 swipe、无批注、无卡片；Immersive-Reading 只做排版且依赖当前聊天；ADHD Reader 无文档。没有一个做"楼内切换 swipe"与"脱敏卡片"。
