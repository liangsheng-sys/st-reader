# T104 交接：卡片模板升级与自制模板

## 做了什么

**① 右栏重排成五组**（可折叠，默认只开"模板"和"遮盖与名字"；手机上预览在上、五组在下）
- **模板**：模板行（内置四套 + 自制）、"导入模板…"、尺寸、书摘设置。
- **配色**：18 组预设（9 浅 + 9 深，多数带渐变）+ 自定义（两个颜色 + 角度）+ 纹理（无 / 格纹 / 点阵 / 横线）。字色按底色自动取深或浅，对比度 ≥ 4.5:1（测试里逐组算过）。
- **排版**：字号（小 / 中 / 大）、行距、字距、对齐（左 / 两端）、内边距、圆角、字体（跟随正文 / 系统衬线 / 无衬线 / 楷体）。
- **页眉页脚**：页眉（开关、12 枚图标、标题、日期）、按语（默认关）、页脚（署名、日期、字数；"ST Reader"跟在署名后面，署名为空就整段隐藏）。
- **遮盖与名字**：原有内容，原样搬进来。

**② 模板就是"底板 + 一组选项值 + 可选 CSS"**
- 内置四套是"全默认选项"的预设，**外观与以前逐像素一致**：四套各导出一张 PNG，T104 之前与之后对比，差异像素 0（`.tmp/t104/before` 对 `after4`）。
- 在预设上改了东西，模板行下面出现"现在的设置和这套模板不一样了 · 还原"。
- "另存为模板…"（顶栏）→ 起名（≤ 20 字）→ 排在内置四套之后；⋯ 菜单（右键、长按同入口）：重命名 / 设为默认 / 导出为文件 / 复制为文本 / 删除。"设为默认"决定下次打开用哪套。
- 模板文件 `{format:'stcr-card-template', version:1, name, base, options, css}`：导出 `.json` 或复制文本；导入选文件或粘贴。
- 校验整份拒绝并说出哪一项：格式 / 版本不对、未知选项键、取值越界、名字不合规、整份 > 20 KB、`css` > 8 KB、清洗后为空。
- `css` 先过我写的检查（`@import`、`@font-face`、外链 `url(`、`position: fixed`、`expression`、卡片之外的选择器都拒绝），再交给 core 的 `cleanStyleText`（带 scope 参数）做第二道，最后给每条选择器加前缀。
- 存储 `stcr:ui:card:templates:v1`（≤ 30 个，每个 ≤ 20 KB），随备份走（备份按键合并，`version` 仍是 1，没有动 core）。

**没做**：任务卡里写"可选"的"背景图只能引用已有素材 id"。这一项会让模板文件格式变复杂（要升 version 2），先记进 01 的 v2 候选。

**C. 原来的四套没有变**
12. 依次点"继承主题""纸张""深色""书摘"：外观和以前一样（继承主题跟着 ST 主题走）。随便改一项（比如圆角），模板行下出现"现在的设置和这套模板不一样了"，点"还原"回到原样。

**D. 手机**

## 我自己定的（前端细节，按 2026-11-09 授权）

1. **五组的顺序**：模板 → 配色 → 排版 → 页眉页脚 → 遮盖与名字，与任务卡一致；折叠状态不记（每次打开回到默认）。理由：是临时调整的地方，记住反而容易让人找不到东西。
2. **"另存为模板…"放在顶栏**（"导出 PNG"左边），不放在右栏里。理由：它与"导出"是同一层意思（把眼前这张卡存下来），放顶栏不受折叠影响。"导入模板…"放在"模板"组里。
3. **默认值表示"不改"**：行距、内边距的"标准 / 默认"=沿用该模板自己的值。理由：这样内置四套像素与以前完全一样。
4. **配色预设 18 组**：浅色 9（奶白、蜜桃、天青、薄荷、丁香、奶油、玫瑰、沙色、云灰），深色 9（墨黑、午夜、森绿、酒红、暮紫、海蓝、可可、石板、极光）。名字都是我起的。
5. **自定义配色字色保底**：两色差得太远、找不到合格字色时，自动把两色压深（或提亮）一点，并在说明里写出来；不静默改。
6. **12 枚页眉图标**（Font Awesome 已加载的）：羽毛笔、钢笔尖、书、翻开的书、卷轴、月亮、星星、茶杯、剧场面具、叶子、心、魔杖。
7. **按语**默认关，最多 80 字；页眉标题最多 30 字，占位"一段故事"。
8. **页脚的日期与字数**合成一小段"2026年11月16日 · 字数"，放在页脚左侧、署名对面；书摘模板里它单独占页脚的最后一行。日期开关在选段第一楼没有时间时置灰。
9. **页眉日期**取选段第一楼的发送时间，格式"2026年11月16日"；没有时间的楼不显示日期。
10. **模板重名**自动加" 2"" 3"；达到 30 个时"另存为"提示"最多存 30 套自制模板，请先删掉不用的"。
11. **菜单入口**：自制模板格子右上角常驻一个小圆 ⋯（22px，手机上点它），右键、长按也能打开；内置四套没有 ⋯（不能改、不能删）。
12. **删除要二次确认**，措辞里提示"可以先导出备份"。
13. **自制模板的 CSS 同时带两种前缀**（`[data-tpl]` 和 `.stcr-tpl-<id>`）：因为导出副本不抄 `data-*` 属性，只有 class 能带过去。这是 core 隐私白名单的限制，不是疏漏。
14. **纹理**不透明度取字色的 8%（点阵 10%），在任务卡要求的 6–10% 内；线与点的间距是固定像素（格纹 / 横线 26–32px，点阵 16px）。
15. **导入框**只认本阅读器导出的格式，外链 / `@import` 会整份拒绝，提示里写明哪一项，没有"部分导入"。

# 追加（人类试用后的两点想法，同一分支）

人类的话："现有配置还是不容易 DIY 出好看的模板；其他项目还有什么优点可以学？""开放类名等，方便有 CSS 知识的用户或其他模型写 CSS，比如'我想要类似 X 推文版式的分享卡片'。"

## 学到了什么 / 做了什么

参考项目（text2image-gui、anyphoto、streamer-card、text2card）里，真正让成品"好看"的不是更多的滑块，而是**几个现成的版式意图**：对白标记（下划线 / 荧光笔）、整体版式预设、外框与阴影、水印。我们的限制（导出是 DOM → PNG、卡片根就是导出根）让"外框 / 水印"成本高，先记 v2；做了前三类里能做的：

- **四个新选项**（"排版"组里）：**版式**（正文 / 气泡：聊天截图样子，你的话靠右、对方靠左）、**对白**（变色 / 不突出 / 下划线 / 荧光笔）、**名字**（小字 / 标签 / 带横线）、**边框**（无 / 细框 / 粗框 / 虚线框）。默认值不加任何类，内置四套再次导出对比：差异像素 0。
- **第六组"自定义样式（写 CSS）"**：输入框，输入后 350 ms 套到预览，状态行写"样式已生效"或"没有生效：原因"；**填入示例（推文版式）**（白底圆角 + 圆形头像位 + 蓝色对白 + 灰色日期）；**复制给 AI 的说明**。
- **给 AI / 会 CSS 的人的指南** `docs/卡片模板CSS指南.md`（也是"复制给 AI 的说明"复制出来的内容）：卡片结构树与稳定类名、CSS 变量、底板与选项类、硬规则、选项取值、输出格式、一份示例、给 AI 的提示。由 `src/ui/cardCssGuide.js` 生成（`node dev/make-css-guide.mjs`），`ui.test.js` 核对文档与代码一致、指南点名的类名都真实存在、示例是合法模板，所以以后改了类名而忘了改指南会测出来。
- 已存模板的 ⋯ 菜单加了"**用现在的设置覆盖它**"（之前只能另存新的）。
- 每楼多 `.stcr-card-mes--user` / `--char` 类，方便写"你的话靠右"这类样式。
- 写示例时踩到的坑都写进了指南：页眉图标是 `<img>`（不能用 filter 改色，会连底色一起变）；选了配色后名字 / 对白颜色要改 `--stcr-c-*` 变量（直接写选择器会输）；配色底色在行内样式里，覆盖要 `!important`；卡片排版宽 540px（导出 2 倍）。

## 追加的人类验收步骤

1. 打开工作台，展开最下面的"自定义样式（写 CSS）"，点"填入示例（推文版式）"：预览变成白底圆角、顶上蓝色小圆标 + "一段故事" + 日期、对白蓝色、底部灰色小字，像一条推文。点"导出 PNG"，图和预览一致。
2. 在框里把 `#1d9bf0` 全改成 `#e0245e`：对白马上变红。再在最前面加一行 `@import url(https://a.invalid/x.css);`：状态行变成"没有生效：不允许 @import……"，预览回到没有这份样式；删掉那一行恢复。
3. 点"另存为模板…"存成"推文"。换到"纸张"：样式自动清空；再点"推文"：回来。改一下框里的颜色，点"推文"右上角 ⋯ →"用现在的设置覆盖它"，换走再回来，是新颜色。
4. 展开"排版"：把版式选"气泡"、对白选"荧光笔"、名字选"标签"、边框选"细框"（先换到"纸张"或"深色"更明显）：正文变成圆角气泡、对白被荧光笔划过、名字变成胶囊标签、卡片里有一圈细框。点模板下的"还原"，一切回来。
5. 选一段含你自己说的话的多楼文字（比如星灯聊天里第 2–3 楼），选"气泡"：你说的话靠右、对方的靠左。
6. 点"复制给 AI 的说明"，粘贴到记事本：是一份写给 AI 的指南。随便发给一个 AI，说"我想要一张便签纸风格的分享卡片"，把它给的 JSON 用"导入模板…"导入试试。

## 追加：我自己定的

16. **做了"选项 + 写 CSS 框 + 指南"，没做"外框 / 水印"**：外框（卡片悬浮在渐变底板上）需要改导出根元素，风险大，记进 01 v2 候选。
17. **第六组放在"页眉页脚"和"遮盖与名字"之间**，默认折叠。理由：它是进阶功能，不该挡住常用的遮盖。
18. **气泡版式固定：你的话靠右、对方靠左、宽不超过 84%**，没做可调。理由：这是聊天截图的通行样子，再给选项只会增加负担。
19. **荧光笔 = 强调色 32% 透明、盖住字的下半段；标签 = 强调色 16% 透明胶囊；细框 / 粗框 / 虚线框距边 16–18px。**数值我定的，看着不对告诉我。
20. **"填入示例"会把底板换成纸张、选云灰配色、字体换无衬线**（示例需要这些），并取消正在使用的自制模板的选中（不会改动已存的模板）。
21. **指南用中文写给 AI**，因为用户用中文提需求；规则 / 类名保持原样不翻译。
22. **导入的 `css` 不变，仍受 8 KB、清洗、前缀约束**；"自定义样式"框的内容也走同一套检查，所以写在框里和导入的结果一致。
23. **模板文件格式没升版本**：新选项键缺失时取默认，所以第一版导出的文件照样能导入；`version` 仍是 1。

# 复查后修正（2026-11-18，Opus 5.5）

说明：本卡原本由 Sonnet 5.5 完成（信名写成了 opus）。人类请 Opus 5.5 复查（另请一位独立复查员专看了模板 CSS 的安全），结论是没有阻断问题，模板 CSS 拿不到外网、碰不到阅读器其他界面；以下几处已在本分支修正。

## 修了什么

1. **对比度保证不完整**：自定义两色渐变时，字色只按两端算，渐变中段可能看不清（例如红→绿，中间只有约 3.4:1）；斜体 / 思维链 / "我的想法"用的颜色完全没检查。现在沿整条渐变取 33 个点一起算，挑色时目标 4.6:1（多留一点余量），字色、名字、对白、斜体、署名在整条渐变上都 ≥ 4.5:1。18 组预设里斜体色有个别会因此深一点点（肉眼几乎看不出）。
2. **另存 / 覆盖时不检查自定义样式**：样式框里写了不合法的 CSS（状态行已说"没有生效"）仍能存成模板，下次打开会被悄悄清空、导出给别人会被拒。现在"另存为模板…"和"用现在的设置覆盖它"都会先检查，不合法就不存，并说出原因（以前覆盖失败一律说"超过 20 KB"）。只有空白的样式当作没有样式。
3. **几处加固**（复查员实测能绕过的写法）：
   - `position: var(--p)` 这类间接写法能变出 `fixed`：现在 `position` 只认直接写出的 static / relative / absolute / sticky。
   - `.stcr-card ~ *`、`.stcr-card + div` 会选到卡片旁边的元素：现在拒绝。
   - 模板 CSS 能画一块巨大的色块盖住预览区里的提示和"点词遮盖"：预览外框加了 `contain: paint`，画出来的东西出不了卡片范围。导出的 PNG 不受影响。
   - 模板文件最外层多出不认识的项（比如 `"evil":1`）以前能导入：现在整份拒绝并说出是哪一项。
   - 自定义样式框加了 8192 字上限，不会再因为超长在重开时被悄悄清空。
4. **文档改正**：02 §6 里"署名后面跟 ST Reader"改成实际行为（署名就是那段字，默认"ST Reader"；**留空就不显示署名**，这和 T104 之前"留空仍显示 ST Reader"不同。我保留了新行为：本来就有开关，留空 = 不要署名更直观）；对比度、CSS 规则的说法与代码对齐；《卡片模板CSS指南》同步（由代码生成，测试核对一致）。

## 对原交接信两处说法的更正

## 追加（2026-11-20）：做模板时找到的四个卡片问题

1. **模板能定强调色了**：选项里新增 `accent`（`null` = 跟随底板 / 配色，或 `#rrggbb`）。页眉图标、遮盖的色块和小图案都跟它走（用户在"遮盖样式"里另选了颜色时仍以用户为准）；`--stcr-card-accent` 变量也是它。工作台"配色"组里多了一行"强调色"，可以直接点选，存模板时一起存。纸张底板不再必然是暗红。
2. **每楼带原楼号**：每楼多一个 `<span class="stcr-card-mes-no">14</span>`，默认隐藏，模板写 `.stcr-card-mes-no { display: inline; }` 就显示。数字和阅读器里"第 14 楼"是同一个数（ST 楼号 #13 + 1）。因为导出时会丢掉 CSS 计数器 `counter()`，这里给的是真文字，导出图里也在。
3. **纸张署名前的"— "改用 CSS 加**：模板写 `.stcr-card-sign::before { content: none; }` 就能去掉。外观和以前一样。
4. **导出库认不了的写法写进了《卡片模板CSS指南》**：`counter()`、`::first-letter` / `::first-line`、`content` 里的英文直引号（用中文弯引号或 `\201C` 转义就行）。这三处是导出库本身的限制，没有改库（`vendor/` 不是我的）。

改动：`src/ui/cardTemplates.js`（+accent 选项）、`src/ui/cardStudio.js`、`style.css`（两条）、`src/ui/cardCssGuide.js` 与生成的指南、`docs/02_UI_SPEC.md` 一格、`src/ui/cardTemplatesBrowser.test.js`（+4 项）。没有改 `src/core/`。

测试：`node src/ui/ui.test.js` 65 项全过；浏览器 `stcrSelfTest({core:false,cardTemplates:true})` 66 项全过（新增：楼号默认藏着且是"4"、署名破折号来自 ::before、导入带 accent 的模板后强调色变量正确、模板 CSS 能打开楼号并去掉破折号）。
