# T23b 交接：自己定替换规则、导入自己的小图片

分支：`task/T23b-replace-rules`（建在 T23a 之上）。任务状态：**通过**（2026-09-29）。

## 做了什么
- **管理替换规则**：分享卡片右边的"管理替换规则…"现在能点了，打开后右边变成"我的替换规则"页（点"← 返回卡片设置"或按 Esc 回来）。
  - 每条规则：**原词** → 换成**文字**或**图案**（内置小图标或你导入的图片）；**范围**：全部聊天 / 仅某个角色；**区分大小写**、**整词匹配**。
  - 能加、能改（笔）、能删（垃圾桶，会问一次）。规则永久保存，下次做卡片自动生效。
- **三个地方可以加规则**：
  1. 管理页里的"+ 添加规则"。
  2. 卡片预览里：点一个词先遮住 → 再点这个遮盖 → 小菜单里"**总是替换为…**"。
  3. 阅读器里选中一个词 → 浮层"屏蔽"右边的小 **▾** → "**设为替换词…**"。
  - 另外：右边"名字替换"列表每一行右边有支小笔。点"我的规则"那行 = 改这条；点"自动"那行（比如"星灯 → char"）= 给它定自己的替换，比如换成"阿星"。
- **名字替换列表**：现在分"我的规则"（亮色标签）和"自动"两种，下面写着优先级：我的规则 > 自动 > 屏蔽词，长词先换（"今晚的星图"先于"星图"）。
- **我的图片**：管理页下半部分。点虚线格"导入图片"，从电脑里选 PNG / JPG / WebP / SVG（每张不超过 200 KB，最多 30 张）。点名字能改名；点 × 删除——如果有规则在用这张图，会写明"有 N 条替换规则在用（哪些词）"，确认后连规则一起删。
- **导入的图片能用在四个地方**（每个图案选择条的最后都有导入格）：替换规则的图案、遮盖样式"小图案"的默认图案、单个词的小图案、**书摘模板的封面**。
- **一个安全提醒**：如果你要加的原词只是某个会被自动替换的名字的一部分（比如"虚构"是"测试旅人（虚构）"的一部分），编辑框会先提醒一次，因为"我的规则优先"会让那个名字只换掉一截、其余真名露出来。确定就这样的话再点一次保存。这个问题我记在了 06 I019，请 astra 看看 core 能不能改得更安全。
- 规则、图片、单个词的遮盖样式都跟着 T22 的**备份**一起导出、导入。

## 人类验收步骤（必填，小白可操作）
**先准备**：浏览器下载位置设到 E 盘（和 T23a 一样：设置 → 下载 → 位置，选 `E:/st-reader/.tmp`）。再准备一张小图片（200 KB 以内的 PNG，比如截一个小表情存成 PNG，放在 E 盘）。

1. 资源管理器地址栏粘贴 `E:/st-reader/dev`，回车，双击 **start-dev-st.cmd**。出现 **listening … 8100** 后，浏览器打开 **http://localhost:8100**。
2. 点名片图标 → **星灯（虚构）** → 顶栏**书本图标**打开阅读器。鼠标移到第 12 楼名字行，点最右边的 🖼。
3. **管理页**：右边往下找到"名字替换"，点 **管理替换规则…**。点 **+ 添加规则**：原词填 **灯塔**，文字填 **某地**，范围默认是"仅 星灯（虚构）"，点 **添加规则**。列表里出现"灯塔 → 某地"。
4. 再加两条，看"长词先换"：原词 **今晚的星图** → 文字 **夜景**；原词 **星图** → 点"**图案**"→ 点**月亮**。
5. **导入图片**：再加一条，原词 **天气** → 点"图案"→ 点最后的虚线 **+**，选你准备的小图片。它被选中后，点**添加规则**。下面"我的图片"里出现这张图；点它的名字改成"猫爪"，回车。
6. 点 **← 返回卡片设置**。卡片上：灯塔 → 某地，"今晚的星图" → 夜景（而不是月亮），天气 → 你的图片。右边"名字替换"里这几条标着"**我的规则**"。
7. **覆盖自动名字**：右边"名字替换"里"星灯（虚构） → char（自动）"那一行，点右边的小笔，文字填 **阿星**，点添加规则。卡片名字行变成"阿星"，这一行变成"我的规则"。
8. **总是替换为…**：在卡片上点"记录"这个词，它被遮住；再点这个遮盖 → 小菜单里点 **总是替换为…** → 文字填 **写下** → 添加规则。卡片上变成"写下"，右边"临时遮住"里它没了。
9. **图片当遮盖和封面**：右边屏蔽词里加 **清楚**；遮盖样式点**小图案**，下面一排图标里点你的图片——"清楚"变成三个你的小图。模板点**书摘**，右边"书摘"里"封面"点你的图片——底部左边的封面方块变成你的图片。
10. **导出**：点**导出 PNG**，打开下载的图片：某地、夜景、你的图片替换、阿星、写下都在，"清楚"是你的小图，封面是你的图。
11. **删除在用的图片**：点**管理替换规则…**，在"我的图片"里鼠标移到"猫爪"上点 **×**：弹出"有 1 条替换规则在用'猫爪'（天气）……"，点"连同规则一起删除"。返回卡片设置：天气变回文字，"清楚"变回小星星，封面变回默认方块，不报错。
12. **阅读器里设为替换词**：Esc 关掉工作台。在第 12 楼正文里选中"虚构"两个字，浮层"屏蔽"右边点 **▾** → **设为替换词…**，文字填 **假想**，点添加规则：**会先出现一段黄字提醒**（"虚构"是名字的一部分）。这是故意的：点**取消**不要加它。
13. **范围**：左上 ≡ → 按角色 → 群组 **STCR · 雾岛观测队（虚构）**，打开聊天，点**纸舟（虚构）**那一楼（第 3 楼）的 🖼：卡片里"留在灯塔"的"灯塔"**没被换**（那条规则只作用于星灯）。Esc 关掉。
14. **备份**：右下角 **Aa** → `⋯` → 导出我的批注与收藏，再**导入**同一个文件，确认框里能看到"替换规则""图片"那几行（重复跳过）。
15. **最重要**：Esc 退出阅读器（按两三下），回到 ST，星灯最后一楼仍是 **3/5**，聊天没有变化。
16. 告诉我"通过"或哪一步不对。

用完在黑窗口按 **Ctrl+C** 停止。
