# T72 交接：显示不出来的楼改为"原样显示"，裸 HTML 只框住真正的网页盒子

## 做了什么

- **原样显示（I051）**：某一楼的某个候选在格式化时出错（正则、Markdown、HTML 接线任何一步抛错），不再只剩一句"（第 N 楼显示失败）"。现在显示的是**没经过任何处理的原文**：
  - 原文转成纯文字，保留换行，里面的 HTML 不执行；
  - 名字旁有淡色小标签"原样显示"；
  - 点 ⋯ 会出现 🐞"复制错误信息"，复制的内容包括阅读器版本、楼号、候选号、时间、浏览器、错误和出错位置，**不含聊天正文**，同时把错误打到浏览器控制台；
  - 候选切换照常能用，换到好的候选就恢复正常排版；
  - 脱敏显示开着时原文照样遮词，遮词失败就不显示原文。
- **裸 HTML 边界（D35）**：只有 `div / style / section / table` 等"盒子"标签能起始一段网页。`<details>` 折叠、`<p>`、标题、`<span>`、`<selection>` 这类自定义标签都留在正文里，交给 ST 同样的格式化器（`<details>` 照常可折叠）。一段网页在标签全部闭合处结束，后面只有空白、紧接着又是盒子标签才算同一段。原来的问题是：`</div>` 后面的 `<selection>` 和 `<details>` 会被一起塞进沙箱。
- **合成样本**：纸舟聊天新增第 11 楼，模仿社区那张卡的结构，内容全部虚构：
  - 散文、三个 details（摘要 / 平行事件 / 主线记录）、带渐变胶囊的样式盒、带 `<style>` 的状态栏、`<selection>` 选项、小剧场 details；
  - 第 1 个候选正常显示；
  - 第 2 个候选开头带一个测试记号，只在 8100 开发实例里故意走"原样显示"，供你验收。
