# T80 交接：楼层胶囊（上一楼 / 下一楼）、隐藏 HTML 工具条、手机顶栏 ✕

## 做了什么
- **跟随条改成"楼层胶囊"**（反馈 2、8）：
  - 正文列右边一直有一枚竖着的细胶囊，写着你正在读的这一楼是谁说的；有多个候选时下面还有 `2/5`，收藏过有一个小标记。
  - 鼠标移上去（手机上点一下）往下展开一列：↑ 上一楼、⤒ 回到这一楼开头、↓ 下一楼、‹ 2 / 5 ›（换候选，点数字出列表）、收藏（多候选楼收藏这个候选，单候选楼收藏这一楼）。展开不变宽，不往字上盖。点别处收起。
  - 位置：正文列旁边的空白放得下，就停在列外 16px，**不压字**；放不下（手机、很窄的窗口、正文开得很宽），贴在正文区边缘，这时平时半透明，碰到才实。
  - Aa → 显示 → **楼层胶囊 左 / 右**，选哪边记住。按卡不做拖动。
  - 上一楼 / 下一楼会跳过收起来的楼（隐藏用户楼、ST 隐藏楼），把那一楼的名字行放到屏幕顶上。
- **键盘 `[` `]` = 上一楼 / 下一楼**（输入框里打字时不抢）。
  - ⚠ 以前 `[` `]` 是换候选，现在换候选挪到了 **`,` `.`**（就是键盘上 `<` `>` 那两个键，不用按 Shift）。工具提示和使用说明都改了。
- **Aa → 显示 → "隐藏 HTML 工具条"**（反馈 6，默认关）：
  - 打开后，HTML 块上方那条"渲染 / 原文 / 宽度 / 截图"平时不出现，也不占位置；
  - 鼠标移到那块 HTML 上，工具条在块右上角淡入；
  - 手机上块右上角有个淡淡的 ⋯，点它叫出工具条，点别处收起；
  - 切到"原文"时工具条照常显示（不然就没地方切回来了）。
- **手机竖屏顶栏的 ✕**（I054，社区 TauriTavern 反馈）：
  - 顶栏所有按钮都不许被压扁，挤的时候只让标题变成省略号；
  - 手机上"脱敏中"角标只留图标；
  - 阅读器整体让出手机刘海 / 状态栏的安全区。
  - 我们装不了 TT（D37、磁盘铁律），只能在开发实例里用无头浏览器模拟手机核对，结果见下面"自测"。
- README"当前边界"里那句"TauriTavern 据社区反馈可用，作者未在 TT 上测试"在 0.3.0 已经加过了，这次没再动。

## 人类验收步骤

在 **8100** 上验收：双击 `dev\start-dev-st.cmd`，等出现 listening 后用平常的浏览器打开 `http://localhost:8100`。之前开着 8100 的页面，请先**刷新一次**。

**A. 楼层胶囊（窗口放大到全屏，1366 宽左右）**
1. 打开阅读器，左边抽屉找 **纸舟（虚构）** → **STCR-02-代码与长文**。
2. 往下滚到"超长楼开始"那一楼，一直滚。应该看到：
   - 正文右边的空白里只有一枚竖着的小胶囊，写着"纸舟（虚构）"；
   - 它和正文之间有空隙，不压任何字。
3. 鼠标移到胶囊上，它往下展开出一列按钮。点 **↓**：屏幕跳到下一楼，那一楼的名字行在最顶上。
4. 再点 **↑**，回到上一楼开头。在长楼中间点 **⤒**（中间那个），回到这一楼开头。
5. 滚到"第 6 楼"附近有 3 个候选的那一楼：胶囊上写着 `2/3` 之类的数字；展开后点 ‹ › 能换候选。
6. 键盘：点一下正文空白处，按 `]` 到下一楼、`[` 到上一楼；按 `.` 和 `,` 换当前这一楼的候选。
7. 点右下角 **Aa**，"显示"那一行最后有"楼层胶囊 左 / 右"，点"左"：胶囊跑到正文左边。验完点回"右"。

**B. 隐藏 HTML 工具条**
1. 还在纸舟这个聊天，滚到有"雾岛信箱"手机界面的那一楼。块上方有一条"HTML 渲染 原文 手机 平板……"。
2. 点 **Aa**，"显示"那一行打开 **隐藏 HTML 工具条**，点"完成"。
3. 那条工具条不见了，网页往上挪，占了原来的位置。
4. 鼠标移到这块网页上：工具条出现在块的右上角；移开又淡出。
5. 验完可以关掉这个开关，也可以留着用。

**C. 手机宽度下的 ✕**
1. 按 F12 打开开发者工具，点左上角"手机和平板"小图标（Ctrl+Shift+M），上面选 **iPhone 12 Pro**（390 宽）。
2. 重新打开阅读器。右上角的 ✕ 完整可见；标题太长时变成"纸舟（虚…"省略号。
3. 点 ✕，阅读器关掉。
4. 在这个宽度下，胶囊贴着屏幕右边，半透明；点一下展开，点 ↓ 能连续往下跳。
