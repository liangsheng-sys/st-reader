分支：`task/T23a-card-studio`（建在 T22 之上）。任务状态：**通过**（2026-09-29，含验收后两条意见）。T23b（自己定替换规则、导入图片）等你验收后说"继续"再做。

## 做了什么
- **三个入口打开"分享卡片"工作台**：
  1. 楼层名字行的小工具里最右边新加的 🖼：用这一楼（当前看的候选）做卡。
  2. 选中文字后弹出的浮层里新加的"🖼 卡片"：可以**跨好几楼**选，跨楼时只有它亮着。
  3. 右侧划线面板里，每条划线右边的 🖼（鼠标移上去出现）：用这条划线做卡。
- **预览就是成品**：左边看到什么，导出的图片就是什么（图片是 2 倍清晰度）。
- **四套模板**：继承主题（跟你的 ST 主题一样）、纸张、深色、书摘。
- **三种尺寸**：竖版（1080×1350，字多了自动变长，不会缩小字）、方形 1080×1080、宽版 1600×900。
- **三种遮盖**：涂黑、主题色块、小图案（六个内置图标：星星/爱心/小猫/云朵/月亮/盾牌）。被遮的字是从图片里**删掉**的，不是盖在上面，放大、调亮度都看不出来。"统一长度"开着时，遮 2 个字和遮 8 个字一样长。
- **名字自动替换**：默认开。单聊角色 → char、你 → user、群聊成员 → char1、char2…… 右边列出这张卡上实际换掉了哪些名字（真名只出现在这个列表里，不进图片）。关掉会提醒"卡片上会显示真名"。
- **屏蔽词**：右边可以加、可以删，和阅读器里"屏蔽"按钮用的是同一张表。
- **在预览里点词**：鼠标停在词上出现虚线框，点一下遮住，再点取消；也可以拖选一串一起遮。这种是"临时遮住"，只对这张卡有效；被遮的地方旁边有个小 **+**，点它就变成永久屏蔽词。
- **显示开关**：名字行、思维链、底部署名（可改文字）。
- **书摘模板**：像读书 App 的书摘图，不显示名字行；这段文字上如果有你写的批注，下面会有"我的想法"；底部"摘自《一段故事》· char"，标题可以改、可以关。
- **导出 PNG**：导出时按钮转圈、不能重复点；图片进浏览器下载文件夹，文件名是 `st-reader-card-日期-时间.png`，不带聊天名、角色名。出错会在右下写原因，预览还在。
- 你选的模板、尺寸、遮盖样式、署名会记住（跟着备份一起导出）；名字替换每次都从"开"开始，免得哪次关了忘记开。
- **"管理替换规则…"**按钮现在是灰的，写着"下一版"（T23b 做）。

## 人类验收步骤（必填，小白可操作）
**先做一件事**：浏览器默认把下载放到 C 盘。请打开 Chrome/Edge 的 **设置 → 下载 → 位置**，点"更改"，选 **E:/st-reader/.tmp**（或 E 盘任意文件夹）；或者打开"下载前询问每个文件的保存位置"，到时选 E 盘。

1. 资源管理器地址栏粘贴 `E:/st-reader/dev`，回车，双击 **start-dev-st.cmd**。黑窗口出现 **listening … 8100** 后，浏览器打开 **http://localhost:8100**。
2. 点名片图标 → **星灯（虚构）**，再点顶栏的**书本图标**打开阅读器。
3. **入口①整楼**：鼠标移到最后一楼（第 12 楼）的名字行，最右边的小工具里有一个**图片图标** 🖼，点它。全屏出现"分享卡片"：左边是卡片，名字行写的是 **char**，正文里"星灯（虚构）""测试旅人（虚构）"都变成了 **char / user**；右边"名字替换"下列着这两条，旁边写"自动"。
4. **四套模板**：右边依次点 **纸张 / 深色 / 书摘 / 继承主题**，左边卡片立刻换样子。再点 **方形 / 宽版 / 竖版**，卡片形状跟着变。
5. **屏蔽词**：右边"屏蔽词（永久）"下的输入框里打 **星图**，回车。卡片上"星图"变成一条黑条。依次点 **主题色块 / 小图案**，黑条变成彩色圆角块 / 三颗小星星（小图案下面可以换图标）。点"统一长度"开关，遮盖变短（按原字数）；再点回来。
6. **点词临时遮**：鼠标移到卡片上"灯塔"那两个字，出现虚线框，**点一下**，它被遮住了；**再点一下**，恢复。再点一次遮住，鼠标移到遮盖上，旁边出现一个小 **+**，点它 → 底部提示"已加入屏蔽词"，右边屏蔽词列表里多了"灯塔"。
7. **导出**：点右上角 **导出 PNG**，按钮转一下圈，底部提示"已导出"。打开下载文件夹里的 `st-reader-card-….png`，放大看：名字是 char/user，"星图""灯塔"的位置是实心遮盖、看不出字，样子和预览一样。
8. 右边屏蔽词里点"星图""灯塔"旁的 **×** 删掉它们。按 **Esc** 关掉工作台，回到阅读器原来的位置。
9. **入口②跨楼选段**：用鼠标从第 10 楼正文中间一直拖选到第 12 楼正文中间，松开。弹出的浮层里颜色和"批注"是灰的，只有 **🖼 卡片** 亮着，点它。卡片里是三楼，每楼一个名字（char / user / char），只有你选中的那几段字。
10. **包含思维链**：Esc 关掉。在第 12 楼点"思考了 3 秒"展开思维链，再点这楼的 🖼。右边打开"包含思维链"，卡片正文上面多了一段"思考过程"。
11. **入口③划线 + 书摘"我的想法"**：Esc 关掉。在第 12 楼选中"今晚的星图很清楚"，点**绿色**划线；再点这条绿线 → "写批注"，写"星灯第一次看清星图"，按 Ctrl+Enter。点顶栏**荧光笔图标**打开右侧面板，鼠标移到这条划线上，右边出现 🖼，点它。模板点 **书摘**：卡片只有"今晚的星图很清楚"，下面有"**我的想法**"写着你的批注（里面的"星灯"变成了 char），底部是"摘自《一段故事》· char"。
12. **群聊**：Esc 关掉。左上 **≡** → 按角色 → 群组 **STCR · 雾岛观测队（虚构）**，打开它的聊天，点任意一楼的 🖼。名字是 **char1 / char2 / char3**，右边列出对应的"自动"替换。
13. **最重要**：Esc 关工作台，再按 Esc 退出阅读器（可能要按两三下）。回到 ST，星灯最后一楼仍是 **3/5**，聊天内容没有任何变化。
14. 告诉我"通过"或哪一步不对。说"继续"后我开始 T23b（自己定替换规则、导入图片）。

用完在黑窗口按 **Ctrl+C** 停止。

## 验收后补充（2026-09-29，按你的两条意见）

**意见①：遮盖样式只能整张卡统一改，希望能单独调。**
- 右边"遮盖样式"现在是**默认样式**。想让某个词不一样：**点预览里它的遮盖**，弹出一个小菜单：`跟随默认 / 涂黑 / 主题色块 / 小图案`（选小图案还能挑图标）。一张卡上可以同时有黑条、色块、爱心。
- 右边屏蔽词、临时遮住的每个词条左边多了一个**小方块**，显示这个词现在的样子，点它也能打开同一个菜单。单独设置过的小方块外面有一圈强调色。
- 永久屏蔽词的单独样式会**记住**，下次做卡片还是这样（跟着备份一起导出）；临时遮住的词只对这张卡有效，点"加入永久屏蔽词"时样式一起带过去。移出屏蔽词时，它的样式也一起清掉。
- 同一个菜单里还有"取消遮住"（临时词）/ "加入永久屏蔽词" / "移出屏蔽词"。原来悬停时冒出来的小 **+** 去掉了，都收进这个菜单，少一个会乱跳的按钮。
- "统一长度"仍然是整张卡一起（它是防止从长度猜出原词的，分开设反而容易漏）。

**意见②：选长段时一滚轮，选中浮层就不见了。**
- 我选了"**浮层跟着选区走**"，没有选"放在末尾"。理由：放末尾的话，从下往上选、或者选完想先看开头时又不顺手；跟着走是两种情况都能用。
- 规则：选区开头还在屏幕里 → 浮层在开头上方（和原来一样）；开头滚出去了、结尾在屏幕里 → 浮层移到**结尾下方**；选区比一屏还长、两头都在屏幕外 → 浮层**贴在正文顶端**。所以滚到哪都看得见，松开滚轮直接点"卡片"即可。
- 选区所在的楼如果被翻页释放了（滚得非常远），浮层才会收起。候选列表、跳楼这些贴着按钮的小浮层，滚动时仍然收起（它们跟选区无关）。

**怎么看**
