# T42 交接：Aa 对齐、隐藏思维链、底色与色块选色、遮盖贴行高、名字两个开关

## 做了什么

- **Aa 阅读设置对齐（反馈 1）**：设置面板改成两列栅格——左边一列是标签（右对齐），右边一列是控件（左对齐），每一行的控件都从同一条竖线开始；两条滑杆一样长，数值格定宽。`⋯` 展开的"排版 / 备份"也用同一套栅格。手机上仍是底部半屏抽屉。
- **隐藏思维链（反馈 2）**：原来的"思维链全部展开"开关并进一组三选一 **思维链：折叠 / 展开 / 隐藏**。选"隐藏"后"思考了 x 秒"整行不出现，楼层工具条的 🧠 也藏起来，`R` 键不响应。只是不显示：思维链里的划线照样保存；从批注面板跳到思维链里的划线时会提示去 Aa 改回来。设置会记住。
- **替换文字加底色（反馈 3）**：替换规则选"文字"时多一行"文字底色"：不加 / 8 个预设 / 自定义（调色盘或输入色号）。底色存进规则的 `to.background`；改已有规则时保留原底色，选"不加"时删掉这个字段。卡片上加了底色的字自动用深字或白字，保证看得清。规则列表、映射列表里也按底色显示。
- **色块选色（反馈 4）**：遮盖样式"主题色块"改名"色块"；选色块（或内置小图案）时下方出现同一套颜色选择条，第一格"跟随模板强调色"。单个词也能单独选色：点预览里的遮盖 → 色块 → 选颜色。涂黑保持黑（深色模板为白）。
- **遮盖高度贴行高（反馈 5）**：涂黑和色块的高度 = 所在行的行高（原来是字高 80%），上下正好填满一行；导出 PNG 里一样。
- **遮盖宽度按像素（反馈 6 / I026）**："统一长度"关闭时，遮盖和原词实际显示宽度一致（英文词也对）。做法：先把卡片按 1:1 不缩放排好版再逐词测量，量完才缩小放进预览；字体还在加载时等加载完再排一次。
- **名字替换两个开关（I021）**：工作台"名字替换"拆成 **自动名字**（角色名 / 你的名字 → char / user）与 **我的规则**（如"灯塔 → 某地"），各自独立，每次打开都默认开。关掉自动名字时列表顶上黄字提醒"角色名和你的名字会原样显示"；有规则因为"不能拆开名字"在名字里没生效时，列表底下列出来。规则编辑框里"原词是名字的一部分"的提醒文案按新规则改写，且只在自动名字开着时出现。

## 人类验收步骤（不用读代码）

**启动**
1. 如果 8100 的开发实例开着也没关系，不用关。打开资源管理器，地址栏粘贴 **E:\st-reader\.tmp\opus-dev**，回车。
2. 双击 **start.cmd**。黑窗口出现 **listening** 字样后，浏览器打开 **http://localhost:8101**，按 **Ctrl+F5**。
3. 左上角选角色 **星灯（虚构）**，打开聊天 **STCR-01-正则与多候选**。点顶栏的**书本图标**打开阅读器。

**① Aa 对齐**
4. 点右下角 **Aa**。应看到：左边一列小灰字"翻页 / 字号 / 行距 / 宽度 / 思维链 / 显示"右边对齐成一条线，右边的按钮和滑杆都从同一条竖线开始；"行距""宽度"两条滑杆一样长。点右下 **⋯**，下面多出"排版""备份"两行，也对得上。

**② 隐藏思维链**
5. 在 Aa 里点 **思维链：隐藏**。往下看正文写着"第 5 楼"的那一楼（星灯说话、右上角有 1/3）：原来名字下面的"思考了 1 秒"那一行**整行消失**；鼠标移到这一楼，右侧小工具里**没有 🧠 图标**。
6. 点 **折叠**：那一行回来了（收起状态）；点 **展开**：思考内容全部展开。最后点回 **折叠**。关掉阅读器再打开，选择仍保留。

**③④⑤⑥ 卡片**
7. 鼠标移到正文写着"第 1 楼，星灯在虚构灯塔记录天气"的那一楼，点工具里的 **🖼（用这一楼生成分享卡片）**。
8. 右侧往下找 **屏蔽词（永久）**，输入框里输入 `星图` 回车，再输入 `WWW` 回车。预览里"星图"和最后一行的"WWW"被遮住。
9. **遮盖样式** 点 **色块**：下方出现一排彩色圆点。点浅蓝色（**天青**）：两个遮盖变成浅蓝。再点第一格（斜线/跟随）：回到模板色。
10. 关掉 **统一长度**：遮住"星图"的色块正好两个字宽，遮住"WWW"的色块和原来三个 W 一样宽（不再是固定三个字宽）。每个色块**上下正好填满一行**，不再是矮一截的条。
11. 点 **涂黑**：变成黑条，同样填满一行高。
12. 点预览里遮住"星图"的那块 → 小菜单里点 **色块** → 点粉色（**樱粉**）：只有"星图"变粉色，"WWW"不变。点空白处关菜单。
13. 右侧"名字替换"下点 **管理替换规则…** → **+ 添加规则**。原词填 `灯塔`，换成选 **文字**，下面框里填 `某地`；"文字底色"点黄色（**柠黄**），旁边出现带黄底的"某地"小样。点 **添加规则**，再点 **← 返回卡片设置**。预览里"灯塔"变成**黄底深色字的"某地"**。
14. **I021 场景**：关掉 **自动名字** 开关。预览名字行变回"星灯（虚构）"，正文里"char / user"变回真名，**但"某地"仍然是某地**；右侧列表顶上出现黄字"自动名字已关闭……"。再打开 **自动名字**，名字又变回 char。
15. 点右上角 **导出 PNG**，到浏览器下载文件夹打开图片：遮盖颜色、宽度、高度与预览一致，屏蔽词看不到，"某地"带黄底。
16. 手机窄屏可选：按 F12 → 左上角手机图标切到手机宽度，Aa 从底部升起，标签和控件同样两列对齐。

**结束**：回到 8101 黑窗口按 **Ctrl+C**，问"终止批处理"时输入 **Y** 回车。这个实例的数据是副本，里面加的屏蔽词和规则只存在 8101 的浏览器存储里，不影响 8100 和你真实的 ST。
