# T97 交接：把聊天导出成能当小说看的文档

## 做了什么

**阅读器顶栏多了一个 ⋮（在笔形图标左边），里面一项"导出为文档…"。**（D43，社区反馈 2、I056）

- **两种格式**：
  - **纯文本 .txt**（默认）：像小说。每楼先写"名字："一行，正文一段一行，楼与楼之间空一行。没有 `*`、`#`、表格竖线这些 Markdown 符号，状态栏这类 HTML 也去掉了。记事本直接能看。
  - **网页 .html**：单个文件，阅读器的"纸张"排版；手机或电脑开了深色模式时自动变成"夜读"配色。思维链和折叠块能点开。没有脚本，断网也能看。
- **可以选的**：
  - 范围：整个聊天，或第几楼到第几楼；
  - 候选：酒馆当前的、你在阅读器里切到的、全部候选（每个候选前写"候选 2/3"）；
  - 说话人：名字、user / char、不标；
  - 包含：楼号、时间、你自己说的话、思维链、HTML 块 / 小剧场（状态栏等）、折叠块、表格、代码块、系统楼和隐藏楼。默认只勾楼号和你说的话。
- **脱敏**：勾上后屏蔽词变 ██，替换规则照换；自动名字开着时，角色名和你的名字变成 char / user，文件名里的名字也一起换。默认跟着 Aa 的"脱敏显示"。
- **文件名**："角色名 - 聊天名.txt"，在浏览器的下载文件夹里。
- **长聊天**：对话框里有进度条，可以点"停止"。上次选的格式和勾选会记住；范围和脱敏每次重来。
- **文字从哪来**：从阅读器排好版的样子里取，也就是显示正则、Markdown 都处理过之后，所以和你在阅读器里看到的一致，不是从原文硬删符号。
- **图片**（只在网页版）：聊天里自带的图片、你 ST 里的图片会放进文件；外站的图片不去取，写成"[图片]"。纯文本里一律写"[图片]"。

**文档**：README"能做什么"一句；使用说明"分享"一节加"导出为文档"；02 §1.1 表格一行、新增 §9.16；03 新增 §5.22；04 T97 改成待验收。CHANGELOG 留给发布复查卡。

## 我自己定的（前端自作主张，逐条说一声）

1. **顶栏新加 ⋮ 菜单。** 原来顶栏没有 ⋯，导出又不是天天用，不值得单独占一个图标。以后不常用的功能都可以放进这个菜单。
2. **TXT 带 BOM、用 Windows 换行**，老版本记事本打开也不会乱码、不会挤成一行。
3. **TXT 里段与段之间不空行，楼与楼之间空一行。** 这样一眼看得出哪是一楼。
4. **网页版跟着系统深浅色**：白天纸张、晚上夜读，同一个文件。
5. **网页版字体**：只写字体名单，不嵌字体（宋体 / 思源宋体，Windows 上会用微软雅黑），文件不会因此变大。
6. **网页版里勾了 HTML 块**：状态栏做成"静态的样子"放进去，能看、`<details>` 折叠能点开，但不跑脚本。靠脚本才出来的内容不会有。
7. **脱敏不记忆**，每次跟着 Aa 的"脱敏显示"走，免得上次关了、这次忘了开。范围也不记，每个聊天楼数不一样。
8. **"部分楼层"的起点**默认是你正在看的那一楼，终点是最后一楼。
9. **内联 SVG 小图标、链接地址不导出**（链接留文字）。读小说用不着，也避免把装饰字当正文。
10. **某一楼排版出错时**，这一楼按原文导出，并在完成提示里说一句；不会因为一楼坏了整个导不出来。

任何一条不喜欢，说一声就改。

## 人类验收步骤

准备：双击 `dev\start-dev-st.cmd`，等窗口里出现启动完成的字样，浏览器打开 `http://localhost:8100`。

1. 点书本图标打开阅读器 → 左上 ≡ →"按角色"→ 纸舟 → 点"STCR-02-代码与长文"。
2. 顶栏右边，笔形图标左边有一个 **⋮**。点它 → 点 **导出为文档…**。弹出对话框，默认是：纯文本、整个聊天、酒馆当前、名字；"包含"里只勾了楼号和我说的话。
3. 直接点 **导出**。对话框关掉，提示"已导出：纸舟（虚构） - STCR-02-代码与长文.txt"。到浏览器的下载文件夹，用**记事本**打开，应看到：
   - 第一行是聊天名；
   - 每楼是"第 N 楼"、"纸舟（虚构）："或"测试旅人（虚构）："起头，下面是正文；
   - 楼与楼之间空一行，没有 `*`、`#` 这类符号，代码块没了。
4. 换"雾岚 → STCR-96-重楼-240楼"，同样导出 TXT：每楼正文下面**没有**"雾岛观测"状态栏。
5. 再打开对话框，应该停在你上次的选择。选 **网页 .html**，勾 **思维链** 和 **HTML 块 / 小剧场**，范围选 **部分楼层**，填 1 到 5，导出。
6. **拔网线或关掉 Wi-Fi**，双击下载的 .html：
   - 是暖白纸色的页面，有标题，每楼一个名字行；
   - 状态栏在，是静态的样子，点"天气"能展开。
7. 星灯（STCR-01-正则与多候选）勾思维链导出网页：每楼正文上面有虚线框"思考过程"，点开能看。
8. 打开对话框，勾 **脱敏**（如果 Aa 里开着"脱敏显示"，它本来就勾着），说话人选"名字"，导出 TXT：名字变成了 user / char，文件名开头是"char - "。
9. （可选）雾岚 → "STCR-95-T30-50MiB-4000楼"，导出：进度条在走，"正在生成：xxx / 4000 楼"；点 **停止** →"已停止，没有生成文件"。不停的话大约十几秒完成，文件约 53 MB。

## 已知问题 / 没做的

- 状态栏、小剧场在网页版里是"导出那一刻排出来的静态样子"，不跑脚本。靠点按钮切换的内容只有初始那一页。
- 网页版里的 HTML 块高度按 640 像素宽排版时定的；手机上变窄会出现块内滚动条。
- 少数情况下（I038 那类，模型写的 HTML 被 Markdown 改了结构），阅读器认不出 HTML 块的位置。这时这一楼会当普通正文导出，状态栏的文字会混在正文里，和阅读器"整楼当一块"的退路一样。
- EPUB / Markdown 按 D43 留在 v2。

## 给下一个人的话

- 改导出文件的样子：TXT 在 `documentText.js` 的 `textLines` / `txtFloor`，网页在 `cleanHtml` / `htmlFloor` / `DOC_STYLE`。Node 测试能直接跑，用假节点，不需要浏览器。
- 网页版的颜色跟着 `readerPalettes.js` 走，改纸张配色时三处会一起变：阅读器、卡片、导出文档。
- `htmlBlockLocate.js` 现在是"认 HTML 块"的唯一一份，阅读器和导出共用。改识别规则只改这里。

## 验收后补充：导出原始聊天（.jsonl）（人类 2026-11-09"加一个酒馆原生的导出 jsonl 按钮，只是为了方便"）

**做了什么**

- 和酒馆聊天列表里的"导出 jsonl"完全一样：用的是酒馆自己的同一个导出接口、同样的参数，下载的就是聊天文件原样。两个样本和磁盘上的文件逐字节比对过，一样。可以拿去别的酒馆导入，或者自己备份。
