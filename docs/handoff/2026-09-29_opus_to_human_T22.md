## 你在 T21 提的两条意见
1. **候选切换 `1/5` 和工具按钮重叠**：已改。工具按钮不再浮在楼层上方，收进名字行、排在 `◂ 1/5 ▸` 左边，平时透明、鼠标移上来才显示，不会压住任何东西。
2. **长楼层只有顶部有候选切换，不方便**：我选了**跟随条**，没做"顶部底部各一个"。
   - 读一楼特别长的内容（比大半屏还高）、名字行已经滚出屏幕时，右上角会浮出一个小条：`名字 · ◂ 2/5 ▸ · ↑`。读完这一楼它就自己消失，普通长度的楼不会出现。
   - 在跟随条上切候选，会自动回到这一楼开头（新候选要从头读）；点 `↑` 只回到开头、不切换。
   - 为什么不放底部：每一楼都多一行按钮会很乱（违反"少按钮"），而且只有读到楼底时才有用。

## 做了什么
- **划线**：选中文字后，上方弹出 `● ● ● ● │ ✎ 批注 │ ⊘ 屏蔽`。点颜色就划线（黄/绿/蓝/粉）。选区跨楼时颜色和批注会变灰。
- **批注**：点"批注"或点已有的划线 → "写批注"。按 Ctrl+Enter 或点外面保存，Esc 放弃。有批注的划线末尾有个小气泡，鼠标停上去能看到批注全文。
- **改划线**：点一条划线 → 换颜色 / 编辑批注 / 取消划线。取消划线只删阅读器里的记录。
- **屏蔽词**：选中一个词（30 字以内）→ "屏蔽"，加入屏蔽词表。它只作用于之后做的分享卡片，阅读器正文和聊天都不受影响。
- **收藏**：楼层工具里 🔖 = 收藏整楼，★ = 收藏当前这个候选（只在有多个候选时出现），键盘 `B` 也可以收藏整楼。收藏后名字前有书签角标、候选数字旁有小星。
- **批注面板**（顶栏荧光笔图标，或按 `/`）：三个页签。
  - 划线与批注：可按颜色过滤、只看有批注的，点一条就跳过去并闪两下。
  - 收藏：本聊天的收藏。
  - 孤立：原文变了、找不到原位置的划线放在这里，可以复制原文或移除，不会自己丢掉。有孤立划线时，顶栏按钮上有小黄点。
- **左侧抽屉"收藏"页签**：汇总所有聊天的收藏。点一条会直接打开那个聊天、跳到那一楼、切到那个候选。
- **备份**（右下角 Aa → `⋯` → 备份）：
  - 导出：生成一个 JSON 文件到浏览器的下载文件夹。
  - 导入：先弹出 ST 的确认框，列出"新增几条、重复跳过几条"，确认后只合并、不覆盖。
  - 有数据且 14 天没导出（或从没导出）时，Aa 上会亮小黄点。
- **阅读设置和进度搬进了 astra 的存储**（I012 完成），会跟着备份一起导出。T21 时存在浏览器里的旧设置会自动搬过来。

## 人类验收步骤（必填，小白可操作）
1. 资源管理器地址栏粘贴 `E:/st-reader/dev`，回车，双击 **start-dev-st.cmd**。黑窗口出现 **listening … 8100** 后，浏览器打开 **http://localhost:8100**。
2. 点名片图标 → **星灯（虚构）**，再点顶栏的**书本图标**打开阅读器。
3. **看意见①**：鼠标移到最后一楼的名字那一行，右边出现 🔖 ★ 🧠 ⧉ 四个小按钮，排在 `◂ 3/5 ▸` 左边，不重叠。
4. **划线**：用鼠标在最后一楼选中"今晚的星图很清楚"，上方弹出四个色点，点**绿色**，文字出现绿色底和下划线。
5. **批注**：点刚才那段绿色文字 → 点"写批注"，随便写一句，按 **Ctrl+Enter**。文字末尾出现小气泡，鼠标停在气泡上能看到你写的话。
6. **收藏**：鼠标移到最后一楼名字行，点 🔖（收藏整楼）和 ★（收藏这个候选）。名字前出现书签角标，`3/5` 旁出现小星。
7. **面板**：点顶栏右边的**荧光笔图标**，右侧面板能看到你的划线（带批注）；切到"收藏"页签能看到两条收藏。点划线那一条，会跳过去并闪两下。
8. **跨聊天收藏**：点左上角 **≡** → 最近 → 打开**纸舟**。再点 **≡** → **★ 收藏**页签，点"第 12 楼 · 第 3 个候选"，应跳回星灯那一楼，而且是 `3/5`。
9. **意见②跟随条**：≡ → 打开**纸舟 STCR-02-代码与长文**，往下滚到"超长楼开始"那一楼的中间。右上角出现"纸舟（虚构） ↑"小条（这一楼只有一个候选，所以没有 ◂ ▸）。点 ↑ 回到这一楼开头，小条消失。
10. **刷新还在**：按 **F5** 刷新整个页面，重新打开阅读器 → ≡ → ★ 收藏 → 点那条收藏。绿色划线、气泡、书签角标都还在。
11. **备份**：点右下角 **Aa** → `⋯` → **导出我的批注与收藏**，浏览器下载文件夹里出现 `st-reader-备份-日期.json`。再点**导入**选这个文件，弹出确认框，写着"重复跳过"，点"合并导入"。
12. **最重要**：按 Esc 退出阅读器（可能要按两三下）。回到 ST，星灯最后一楼仍是 **3/5**，聊天没有任何变化。
13. 告诉我"通过"或哪一步不对。说"继续"后我开始 T23（分享卡片）。

用完在黑窗口按 **Ctrl+C** 停止。
