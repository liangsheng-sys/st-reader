# T73 交接：分享卡片导出保留正文美化（I052）

## 做了什么

- **楼内样式进 PNG**：正则美化出的 `<style>`（信纸底色、圆角、阴影、标题版式）在导出的 PNG 里和预览一致。
- **背景图**：
  - 正文样式里的 `data:` 背景图（花边、小纹样）不再被整段删掉，预览和 PNG 都在。
  - 网上的（https）背景图跟 ST 的"禁止外部媒体"设置走：ST 禁止时阅读器也不加载；ST 允许时，导出会把图读下来嵌进 PNG。
  - 读不到的，那一格画浅色斜纹占位，右侧栏底部提示"有背景图拿不到（…），PNG 里用斜纹占位代替"。其余美化照常导出，不整块丢。
- **气泡边框**：顺手修了一个所有楼都有的差异。"继承主题"模板下，楼层气泡的细边框在 PNG 里没了，现在补回来。原因是 ST 气泡样式写成 `border: 1px solid var(--…)`，旧的复制逻辑读不出这种写法。
- **工作台提示**：
  - 预览下方加了一行小字"预览与导出不一致？"，点开有说明和"复制诊断信息"按钮。诊断信息只有版本、模板、尺寸、遮盖样式、楼层数和上次导出的提示，不含聊天内容。
  - 导出后的提示前缀从"字体提示："改成"提示："，因为现在也会报告图片。
- **测试样本**：纸舟聊天加了第 12 楼"正则美化信纸"，配五条 `stcr-t73-` 全局显示正则，专门用来验收这一卡。

## 复现与根因

我照你上次说的社区写法复现：用正则把 `<letter>`、`<char>`、`【邮戳】` 这类标签替换成自带 CSS 的盒子。预览完整，导出只剩文字。根因有三处：

1. **作用域编号丢失**：快照克隆时把楼内样式的作用域编号 `data-stcr-css` 去掉了，楼内 `<style>` 的规则在副本里一条都不命中。这是主因。
2. **url() 整段删除**：格式化时，样式里只要出现 `url(` 就把整段样式删掉，`data:` 背景也一起没了。
3. **var() 简写读不出**：含 `var()` 的简写（`border:` / `background:`）在复制时各分项读出来是空串，所以被丢掉。

## 人类验收步骤

在 **8100** 上验收：双击 `dev\start-dev-st.cmd`，等出现 listening 后打开 `http://localhost:8100`。如果之前就开着 8100 的页面，请先**刷新一次**。旧页面里还是旧设置，看不到第 12 楼的美化。

**A. 美化楼预览与 PNG 一致**
1. 打开阅读器，左边抽屉找 **纸舟（虚构）** → **STCR-02-代码与长文**，拉到最后一楼（第 12 楼）。
2. 应该看到一张米色信纸，带圆角和淡阴影：
   - 顶上是"✦ 纸舟 ✦"标题；
   - 正文里有一颗橙红色渐变的"邮戳"胶囊；
   - 下面一排小圆点花边；
   - 最底下一格虚线框，写着"这一格的背景是网上的图片……"。
3. 鼠标移到这一楼，点右上角 ⋯ → 图片图标（"用这一楼生成分享卡片"）。工作台里的预览应该和第 2 步一样。
4. 点右上角 **导出 PNG**，打开下载文件夹里的 `st-reader-card-….png`，和预览并排看：
   - 信纸底色、标题、邮戳、圆点花边都在；
   - 外面那圈楼层气泡的细边框也在。

**B. 网上的背景图拿不到时有占位和提示**
1. 关掉工作台和阅读器。点 ST 顶栏的"用户设置"（人形图标），在设置里的搜索框输入"外部"，**取消勾选"禁止外部媒体"**（英文界面叫 Forbid External Media）。
2. 重新打开阅读器 → 纸舟第 12 楼 → ⋯ → 图片图标 → 导出 PNG。
3. 应该看到：
   - PNG 里虚线框那一格铺着浅灰斜纹，其余照旧；
   - 右侧栏最底下出现"提示：……有背景图拿不到（Failed to fetch），PNG 里用斜纹占位代替（https://example.invalid）"。这个地址是虚构的，永远拿不到，所以一定走占位。
4. 验完请回到用户设置，**重新勾上"禁止外部媒体"**。这个开关会存进开发实例的设置。

**C. "预览与导出不一致？"**
1. 在工作台预览下方，操作提示下面有一行带虚线下划线的小字"预览与导出不一致？"，点一下。
2. 展开一段说明，下面有"复制诊断信息"按钮。点它，底部提示"已复制诊断信息（不含聊天内容）"。
3. 找个记事本粘贴，应该能看到：
   - 版本、模板、尺寸、遮盖样式；
   - "楼层：1 段，其中 1 段带楼内样式"；
   - 上次导出的提示。

   里面不应该有信纸里的任何正文。
4. 再点那行小字，说明收起。
5. 把窗口拉窄到手机宽度，这行小字和展开的说明都不超出屏幕。

## 已知问题 / 没做的

- **动画只留一帧**：楼内样式里的动画和过渡在 PNG 上只保留静止的一帧，说明里已经写明。
- **相对路径背景图**：`url(images/…)` 这类相对地址仍然换成 `none`，预览和 PNG 都不显示，和以前一样，避免去请求 ST 同源路径。
- **网站不允许读取的图**：外链图片要网站允许跨域读取才能嵌进 PNG。很多图床不允许，这时就是斜纹占位加提示。这属于 D23 的边界，不走代理。
- **测试环境里的一个坑**：停服改 `.dev` 的 settings.json 时，如果还有旧的 8100 页面开着，它缩放窗口时会把内存里的旧设置存回去。这是 ST 自己的 `/api/settings/save`，只读名单本来就不拦它。我第一次就是这样被覆盖的，已写进 `dev/fixtures/README.md`。
