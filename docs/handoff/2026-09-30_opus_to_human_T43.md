# T43 交接：抽屉"按角色"跟随 ST 排序 + 标签 + 搜索，收藏改为"收藏的聊天"

## 做了什么

- **按角色页（反馈 7、F12、D20）**
  - 顶部一行：**角色 / 群组** 切换 + **排序下拉**。下拉第一项是"跟随 ST（A-Z）"——括号里是你在 ST 角色列表里此刻选的排序；顺序和 ST 里看到的一致（比较方式照 ST 自己的代码：收藏排序时收藏的在前，名字用浏览器默认语言比较）。其余选项与 ST 下拉一一对应：A-Z、Z-A、最新创建、最早创建、收藏的在前、最近聊过、聊天最多 / 最少、内容最多 / 最少。在这里改只影响这次打开阅读器，不写回 ST；ST 选"随机"时退回 A-Z。
  - 下面一行 **ST 标签**：只列有角色在用的标签，点选多个 = 都要有（和 ST 一样），选中的排到最前，有"清除"。标签多时只露两行，"全部标签（N）▾"展开。群组页只有排序 + 搜索。
  - 过滤框在这一页变成 **"搜索 404 个角色…"**，按名字即时过滤。
  - ST 里收藏过的角色，名字后有一颗小金星。
  - **虚拟滚动**：几百个角色时只画看得见的几十行（400 个角色时页面里约 25 行），滚动、搜索都不卡。
- **收藏整个聊天（反馈 8、F13、D19）**
  - 任何聊天行（最近 / 按角色展开后 / 收藏 / 当前）鼠标移上去，右上角出现 **☆**，点一下收藏（变金色常亮），再点取消。
  - 阅读器**顶栏右侧**多一个 ☆：收藏正在读的这个聊天。两处同步。
  - 抽屉 **"收藏"页只列收藏的整个聊天**（最近收藏的在前）。楼和候选的收藏不再出现在抽屉里，只在右侧"划线、批注与收藏"面板（"本聊天 / 全部聊天"切换保留）；面板里也不会混进"整个聊天"的收藏。
- **core 接口（I029）**：core 的角色列表只给名字和头像，没有排序字段、标签和 ST 当前排序。已在 06 写清需要的接口；界面先用一个临时适配层 `src/ui/ownerMeta.js` 做完——它只读 ST 页面内存里已有的角色 / 标签 / 排序设置（不发请求、不改任何值），core 补上接口后只改这一个文件。

## 人类验收步骤

**启动**
1. 资源管理器打开 **E:\st-reader\.tmp\opus-dev**，双击 **start.cmd**。出现 listening 后，浏览器打开 **http://localhost:8101**，按 **Ctrl+F5**。（这次 ST 左侧角色列表会有 400 多个角色，这是合成样本。）

**① 跟随 ST 排序**
2. 先在 ST 自己的角色列表（右上角人像图标）里，把排序下拉选成 **Recent（最近）**。
3. 点顶栏**书本**打开阅读器 → 左上 **☰** → **按角色**页签。排序下拉写着 **"跟随 ST（最近聊过）"**，列表最上面几个角色和 ST 角色列表最上面几个一样。
4. 在阅读器的排序下拉里改成 **A-Z**：列表立刻按名字排。关掉阅读器（Esc）再打开，又回到"跟随 ST"。ST 自己的排序没有被改动。

**② 10 秒内找到一个角色**
5. 在"搜索 404 个角色…"框里输入 **林惊鸿·10**：列表只剩这一个。清空搜索框。
6. 点标签 **科幻**，再点 **悬疑**：只剩两个标签都有的角色，这两个标签跳到最前。点 **× 清除** 恢复。
7. 用鼠标滚轮从头滚到底：一路顺滑，不卡。
8. 点 **群组**：只剩"STCR · 雾岛观测队（虚构）"，没有标签行。点回 **角色**。

**③ 收藏整个聊天**
9. 搜索 **程长歌**，点第一个"程长歌（虚构）"展开，鼠标移到下面的聊天"合成聊天-13"上，右上角出现 **☆**，点它：变成金色星，底部提示"已收藏这个聊天"。
10. 点页签 **★ 收藏**：只看到"程长歌（虚构）· 合成聊天-13 · 收藏于 今天 …"。点它打开这个聊天。
11. 看阅读器**顶栏右边**：多了一颗金色 ★（已收藏）。再点它：变回空心，抽屉收藏页里这一条消失。
12. 打开 **星灯（虚构）/ STCR-01**，把鼠标移到某一楼，点书签收藏这一楼。再点顶栏 ☆ 收藏这个聊天。
13. 点顶栏 **荧光笔图标**打开右侧面板 → **收藏** → **全部聊天**：只有"第 N 楼"这一条楼层收藏，**没有**"整个聊天"的收藏；左侧抽屉"收藏"页只有聊天，**没有**第 N 楼。两处不重复。

**结束**：8101 黑窗口按 **Ctrl+C**，输入 **Y** 回车。
