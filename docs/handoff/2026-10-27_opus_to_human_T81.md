# T81 交接：脱敏统一（自动名字全局开关、Aa 直达规则管理、一条规则多个原词）

## 做了什么
- **Aa 新增"脱敏"一行**。原来"显示"行里的"脱敏显示"挪到这里，旁边多了两样：
  - **自动名字**（默认开）：角色名换成 char、你的名字换成 user。
  - **管理屏蔽词与替换规则…** 按钮。
- **自动名字是一个全局开关**（D38）：
  - 脱敏显示开着时，下面这些都跟它走：正文、名字行（显示成 char / user）、顶栏标题、批注面板和抽屉里的小字、HTML 块里的文字。
  - HTML 块和代码块的"复制脱敏版代码"也跟它走。
  - 分享卡片工作台和 HTML 截图窗口打开时，"自动名字"开关从这里的值开始。窗口里关掉只管这一次，下次打开又回到全局值。
  - 脱敏显示开着时拨这个开关，正文马上重排，不用刷新。
- **Aa 里一键到规则管理**：点按钮弹出一张面板"屏蔽词与替换规则"。
  - 上面一节是屏蔽词（和卡片、截图用的是同一张表），可以加、可以删。
  - 下面是替换规则和"我的图片"，就是卡片工作台里那一页。
  - Esc、×、点面板外面都能关。关掉时如果改过东西，而且脱敏显示开着，正文按新规则重新显示。
- **一条规则可以有几个原词**（D36）：
  - 编辑规则时，"原词"下面多了一个"更多原词"框，一行写一个，可以不填。比如原词"灯塔"，更多原词写"灯台"，两个词都换成"某地"。
  - 规则列表里显示成 `灯塔、灯台 → 某地`。
  - 同一个范围里，任何一个原词已经被别的规则用了，会提示你去改那一条，不会重复建。
  - 卡片、HTML 截图、脱敏显示、复制脱敏版、批注里的字，全都认这几个原词，长词照旧先换。
- 顺手修了一处小毛病：规则编辑框"文字底色"右边会多出一个英文 "null"。现在没有了，卡片工作台里也一样。

## 人类验收步骤

在 **8100** 上验收：
1. 双击 `dev\start-dev-st.cmd`，等出现 listening。
2. 用平常的浏览器打开 `http://localhost:8100`。之前开着 8100 的页面，请先**刷新一次**。

**A. 脱敏显示时名字变成 char / user**
1. 打开阅读器，左边抽屉找 **纸舟（虚构）** → **STCR-02-代码与长文**。
2. 点右下角 **Aa**。最下面有新的一行"**脱敏**"：脱敏显示 · 自动名字 · 管理屏蔽词与替换规则…
3. 打开 **脱敏显示**。应该看到：
   - 每一楼名字行的"测试旅人（虚构）"变成 **user**，"纸舟（虚构）"变成 **char**；
   - 左上角标题也变成 **char**；
   - 右上角出现"脱敏中"。
4. 关掉 **自动名字**：名字马上变回真名。再打开，又变回 char / user。

**B. 复制脱敏版代码**
1. 保持脱敏显示和自动名字都开着，往下滚到"雾岛信箱"那块 HTML，或者上面任意一个代码块。
2. 点块上方工具条里的 **面具图标**（复制脱敏版代码）。
3. 随便找个记事本粘贴：凡是完整写出"测试旅人（虚构）"或"纸舟（虚构）"的地方，都已经是 user / char。
   - 注：这个样本 HTML 里写的是不带"（虚构）"的"测试旅人"，那几处不算完整名字，会原样保留。卡片一直是这个规则。
4. 回 Aa 关掉 **自动名字** 再复制一次：这次名字原样不换，提示里会写"自动名字已在 Aa 里关掉"。

**C. Aa 直达规则管理 + 一条规则两个原词**
1. Aa → **管理屏蔽词与替换规则…**：弹出一张面板，上面是"屏蔽词"，下面是"我的替换规则"。
2. 点 **添加规则**：
   - 原词填 `超长`；
   - "更多原词"框里填 `没有`；
   - 换成填 `某地`；
   - 点 **添加规则**。
3. 列表里出现一行 **超长、没有 → 某地**。
4. 点 × 关掉面板。第一楼"……超长楼和没有思维链的候选"变成"……**某地**楼和**某地**思维链的候选"，两个词都换了。
5. 验完可以回到面板，点这一行的垃圾桶删掉。

**D. 卡片和截图从全局起步**
1. Aa 关掉 **自动名字**，选中一段文字点"卡片"。工作台右边"名字替换"里的"自动名字"是**关**的。
2. 在工作台里把它打开（只管这张卡），关掉工作台。
3. 再开一次工作台：它又是关的，跟着 Aa。
4. HTML 截图窗口（相机图标）也是这样。
5. 验完把 Aa 里的自动名字开回去。

## 已知问题 / 没做的
- **小字只认得当前聊天的名字**：抽屉里别的角色的聊天标题、批注面板"全部"里别的聊天的摘录，名字不换（不知道那边是谁，不猜）；屏蔽词和替换规则照常。同一个角色的别的聊天会换。
- 名字匹配是完整名字：角色叫"测试旅人（虚构）"，正文里只写"测试旅人"不会被自动换。想换就加一条规则："测试旅人"，更多原词里再写别的叫法。
- 规则面板从 Aa 打开时，在输入框里按 Esc 会关掉整张面板（和"使用说明"面板一样）。
- 合并提醒：T80 分支（还没合进 main）也改了 Aa 的"显示"一行和 `reader.js` 的 `applyPrefs`，合并时这两处会冲突，要手工把两边都留下。

## 给下一个人的话
- "要不要换名字"只看 `prefs.autoNames`。正文走 `redactFor → names`，小字走 `sideRedaction`，HTML 沙箱走 `prepare`，复制和截图走 `htmlMaskOptions`，四条线都在 `reader.js`。
- 正文脱敏要从 core 的结果里找回每处原词的长度（为了划线不错位）：`redact.js` 的 `replacePieces` 用"规则的全部原词 + 自动名字"去对。以后给规则加新的匹配方式，这里也要跟着加。
- 规则管理页 `createRulesManager` 多了两个参数：`words`（顶上带屏蔽词一节）和 `backLabel`（null 时不出"返回"按钮）。卡片工作台和截图窗口还是原来的用法。
