# T44b 交接：HTML 楼层渲染、截图分享、复制脱敏版

## 做了什么

- **楼里直接渲染**：模型写的网页 / 小游戏（围栏代码里有 `<body>`，或整楼就是一份 HTML）在阅读器里直接显示出来，能点、能滚，高度自动跟着内容。放在安全的沙箱里运行，碰不到 ST 和你的聊天。
- **一条细工具条**：`</> HTML [渲染|原文] [手机|平板|桌面|跟随正文] ⊕ 🕵 📷`
  - **渲染 / 原文**：随时切换。划线在原文里做，来回切划线不受影响。
  - **宽度四档**：手机 390 / 平板 768 / 桌面 1200 / 跟随正文。比正文宽的时候，渲染区会向两边伸出去；还放不下就左右滚动。最近选的一档会记住。
  - **⊕ 外链**：按你的意思**默认允许**（只允许 https）。点一下，只对这一块断网。
  - **🕵 复制脱敏版**：屏蔽词遮住、替换规则和名字（char / user）都换好，再复制。只换文字，标签、属性、脚本原样保留，粘到在线工具里能直接渲染。
  - **📷 截图**：见下。
- **Aa → ⋯ → HTML 一行**：**渲染 / 原文**（打开聊天时默认显示哪种）+ **允许外链**开关（关掉后所有 HTML 都断网）。
- **截图分享**：全屏窗口，左边选宽度、清晰度（1/2/3 倍）、自动名字 / 我的规则，右边是**脱敏后**的预览。可以直接保存整张；也可以在图上拖出一个框，只保存框里的部分（框能移动，四个角能调大小）。截图始终断网。
- **普通代码块**右上角也多了一个 🕵：复制脱敏版。
- 脱敏显示开着的时候，沙箱里显示的也是换过词的 HTML。
- 沙箱只在滚到附近时才建；换候选、切到原文、关掉阅读器时都会销毁，不会在后台一直跑。

## 验收后补充（2026-10-01）

人类意见：① 独立截图里改不了屏蔽词 / 规则，要回卡片工作台很麻烦；② 允许外链时截图里会不会有外部素材；③ 截图是"刚打开的样子"不好：要么和阅读器进度一致，要么能互动，或者至少能把界面拉长让所有聊天出现在一张图里。

- **① 设置搬进截图窗口**（没有往卡片工作台加渲染视图：卡片是排版好的文字卡，HTML 是整页截图，两种预览差别太大，硬塞一起反而难用）。截图窗口右边现在和卡片工作台同样的设置栏：宽度、清晰度、**长图**、名字替换（自动名字 / 我的规则 / **管理替换规则…**，打开的是同一个管理页）、**屏蔽词（永久）**、**临时遮住（只这张图）**。屏蔽词和卡片、脱敏显示是同一张表。
- **② 外部素材**：目前不会出现——截图始终断网。能不能带上要 core 改，而且只有允许跨域的网站的字体 / 图片能画进图片，其余的浏览器本身就不让画。已写进 06 I032，等你决定要不要做。
- **③ 长图**（默认开）：把手机界面里那种固定高度、要滚动的聊天列表展开，所有消息出现在一张图里（实测纸舟手机聊天：390 × 490 → 390 × 760，六条消息全在）。"和阅读器里当前进度一致"（比如游戏点出结局后再截）需要 core 能拿到沙箱里的当前画面，UI 自己做不到，已写成 06 I032 请 astra 评估。
