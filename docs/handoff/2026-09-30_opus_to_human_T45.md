# T45 交接：脱敏阅读模式

## 做了什么

- **Aa → 显示 → 脱敏显示**（开关，会记住）。打开后，阅读器正文、思维链、名字行按你的**屏蔽词**和**我的替换规则**显示：
  - 屏蔽词显示成一串 █（每个字一块），完全看不出原字；
  - 替换规则照规则换成文字（有底色就带底色）、小图标或你的图片；
  - 每处脱敏下面有一道很细的点状下划线；鼠标悬停只提示"此处已脱敏"，**不显示原词**；
  - 顶栏出现一个小胶囊 **"脱敏中"**，点它就关闭脱敏显示。
- 旁边的小字也一起脱敏：右侧面板的划线摘录和批注、鼠标悬停的批注气泡、候选列表、抽屉里的名字 / 标题 / 预览、跟随条、顶栏标题。
- **只改显示**：聊天文件不动，关掉开关立刻恢复原文。复制本楼、复制代码复制的是你看到的样子。
- 自动名字（char / user）不在阅读模式里用——正文满屏 char 很难读；需要的话可以自己加一条"名字 → 某某"的规则。
- **划线不受影响（写清做法）**：每处脱敏在页面里其实是两段——一段是原词，永远隐藏（不显示、不能复制、页面查找找不到）；一段是你看到的替换，标记为"划线不计入"。core 计算划线位置时只数原词、不数替换，所以位置和不脱敏时一字不差：已有的划线照常显示，脱敏时新划的线也按原文保存，开关来回切不会让划线变"孤立"。唯一的小代价：一条划线正好跨过脱敏处时，那几个方块本身不上色。
- core 不需要新接口：用的是 T41 已有的 `replaceNamesInRaw / maskText / maskCodeText`。

## 已知问题 / 没做的

- 一个屏蔽词如果被 HTML 标签隔开（比如一半加粗），阅读器里匹配不到（卡片导出那边能跨标签）。一般的正文不会这样。
- 划线跨过脱敏处时，那几个方块本身不上色（见上面"做法"）。
- 编辑批注时，输入框里是你写的原文（要能改）；悬停气泡里是脱敏后的。

## 验收后补充（2026-09-30）

人类意见：① 脱敏时屏蔽词的长度和原词不一样、高度也比字高；② 小图案在"非统一长度"下能不能和字数一样多；③ 喜欢最早的底部长条 Aa（说的"对齐"是横向对齐），现在的面板也保留，两种可以切换。

- **① 涂黑条**：长度现在正好等于原词在当前字体下的宽度（实测"星图"30px = 30px、"WWW"42.4px = 42.4px），高度 = 一个字高，和卡片里的涂黑一样。换字号自动跟着变。复制出来仍是每字一个 █；页面查找（Ctrl+F）找不到原词。
- **② 小图案个数**：分享卡片里关掉"统一长度"时，被遮的词几个字就放几个图案（"星图"两颗、"WWW"三颗），不再固定 3 个被切掉半个。统一长度开着时仍是 3 个。导出的 PNG 与预览一样。阅读器里"替换规则"的小图标（船票 → ★）是你自己定的替换，仍是一个。
- **③ Aa 两种样子**：默认回到**底部长条**：一行横排，所有项目在同一条中线上。点长条右边 ⊞ 换成两列**面板**；面板右下 ≡ 换回长条。会记住。
